# Questão 6 — Auditoria da estrutura original sobre \(\tau\)

## 1. Veredito curto

O texto original contém a maior parte dos ingredientes necessários para
resolver a Questão 6, mas eles ainda não estavam organizados de modo
consistente.

O ponto aproveitável principal é:

\[
\boxed{
\tau
\text{ aparece corretamente como tempo/parâmetro de fluxo de Perelman com
dimensão de área }L^2.
}
\]

O problema é que o próprio texto também usa \(\tau\) como:

1. tempo físico;
2. variável complexa somável diretamente a \(it\);
3. logaritmo de escala de renormalização;
4. parâmetro adimensional;
5. expoente de kernel com dimensão antiga.

Portanto:

\[
\boxed{
\text{o original ajuda, mas a Questão 6 não estava fechada no original.}
}
\]

Ela fica fechável se adotarmos a separação:

\[
\boxed{
\tau:\text{ fluxo geométrico/difusivo, }[\tau]=L^2;
}
\]

\[
\boxed{
z_\tau=\tau+i\nu_0t:\text{ variável causal complexa};
}
\]

\[
\boxed{
\widehat\tau=\frac{\tau}{\ell_C^2},\quad
s=\log\widehat\tau:\text{ escala adimensional/RG}.
}
\]

---

## 2. O que pode ser aproveitado diretamente

### 2.1 Capítulo 04 — definição dimensional de \(\tau\)

No capítulo `pt-br/04 - A Ação Funcional e Consistência Quântica (Loops).md`,
há uma passagem forte:

\[
\tau
\text{ é tempo de escoamento com dimensão de área }[L^2].
\]

Também aparece a viscosidade cinemática:

\[
\nu_0=\frac{\hbar}{2m_0}.
\]

Isso é aproveitável porque permite corrigir a união com o tempo físico:

\[
\boxed{
z_\tau=\tau+i\nu_0t.
}
\]

O texto original escreve, em alguns lugares, algo equivalente a:

\[
\tau=\nu_0t_{\mathbb C}.
\]

Essa ideia é aproveitável se for reescrita como parametrização dimensional do
plano complexo, não como identificação direta entre \(\tau\) e \(t\).

Forma final recomendada:

\[
\boxed{
[\tau]=[\nu_0t]=L^2,
\qquad
z_\tau=\tau+i\nu_0t.
}
\]

### 2.2 Nota 2.4 — origem difusiva da medida de Perelman

O arquivo `pt-br/notas/2/nota 2.4.md` é um dos melhores trechos para a Questão
6.

Ele explica corretamente que a forma:

\[
u=(4\pi\tau)^{-m/2}e^{-f}
\]

vem do kernel de calor/difusão.

O conteúdo aproveitável é:

1. \(\tau\) é escala difusiva;
2. \(\partial_\tau u=\Delta u-Ru\) fixa a dimensão de \(\tau\);
3. como \([\Delta]=L^{-2}\), segue \([\tau]=L^2\);
4. \(f\) mede o desvio geométrico em relação à difusão plana.

Correção necessária:

No texto final da GDQ, se \(n\) é dimensão complexa e \(d=2n\) é dimensão
real, então:

\[
(4\pi\tau)^{-d/2}
=(4\pi\tau)^{-n}.
\]

Como:

\[
n=4,
\qquad
d=8,
\]

o kernel correto no bulk é:

\[
\boxed{
(4\pi\tau)^{-4}.
}
\]

Portanto, a nota 2.4 é aproveitável, mas deve trocar a ambiguidade
\((4\pi\tau)^{-n/2}\) por:

\[
\boxed{
(4\pi\tau)^{-d/2}
\quad\text{ou}\quad
(4\pi\tau)^{-n}
\text{ quando }d=2n.
}
\]

### 2.3 Nota 4.1 — \(\tau\) como parâmetro de escala/fluxo

O arquivo `pt-br/notas/4/nota 4.1.md` contém formulações aproveitáveis:

\[
f(z,\bar z,\tau)
\]

e a descrição de que o sistema evolui ao longo de um parâmetro de escala
temporal \(\tau\) via dinâmica de Madelung/Perelman.

O trecho é aproveitável se a expressão:

\[
\text{parâmetro de escala temporal}
\]

for entendida como:

\[
\boxed{
\text{parâmetro de fluxo geométrico, não tempo cronológico.}
}
\]

Correções necessárias:

1. a nota ainda usa \(n=2\) em alguns pontos antigos;
2. assume Kähler estrito como base geral;
3. chama \(\tau\) de temporal de forma ambígua.

Na formulação final:

\[
n=4,
\qquad
M=\mathbb R^4\times T^4,
\qquad
\tau\neq t.
\]

### 2.4 Nota 4.4 — evolução geométrica em \(\tau\)

O arquivo `pt-br/notas/4/nota_4.4_convergencia_fluxo.md` é aproveitável para
mostrar que \(\tau\) aparece naturalmente como parâmetro de evolução do fluxo:

\[
\frac{\partial g_{ij}}{\partial\tau}
=
-2R_{ij}
+\frac12H_{ikm}H_j{}^{km}
+2\nabla_i\nabla_jf.
\]

Também aparece:

\[
\frac{d\mathcal E}{d\tau}
\le
K\mathcal E(\tau).
\]

Essas expressões são úteis para a Questão 6 porque mostram que derivadas em
\(\tau\) são derivadas de fluxo geométrico.

Mas isso não deve ser lido como evolução cronológica local. A leitura correta
é:

\[
\boxed{
\partial_\tau
\text{ mede variação de resolução/fluxo geométrico.}
}
\]

Na camada física local, o tempo cronológico continua sendo \(t\).

### 2.5 Capítulo 06 — uso correto de \(t\) em aplicações estacionárias

O capítulo `pt-br/06 - Aplicações Simples.md` usa, no poço infinito:

\[
\frac{\partial S_R}{\partial t}
+\frac{(\nabla S_R)^2}{2m}
+V
-\frac{\hbar^2}{2m}\frac{\nabla^2R}{R}
=0.
\]

E, para estado estacionário:

\[
S_R=-Et.
\]

Isso é importante porque mostra que o próprio texto original já sabe usar
\(t\) como tempo físico nas aplicações.

Portanto, a separação final é coerente com o original:

\[
\boxed{
t=\text{tempo físico em aplicações};
\qquad
\tau=\text{fluxo geométrico/de escala}.
}
\]

## 3. O que precisa ser corrigido

### 3.1 \(\tau+it\) deve ser substituído

Em `4-55.md`, aparece:

\[
\mathcal T=\tau+it.
\]

Isso é dimensionalmente incorreto, pois:

\[
[\tau]=L^2,
\qquad
[t]=T.
\]

A correção oficial deve ser:

\[
\boxed{
z_\tau=\tau+i\nu_0t,
\qquad
\nu_0=\frac{\hbar}{2m_0}.
}
\]

Assim:

\[
[z_\tau]=[\tau]=[\nu_0t]=L^2.
\]

### 3.2 \(t=-i\tau\) deve ser rejeitado

Qualquer trecho que use rotação de Wick como:

\[
t=-i\tau
\]

deve ser rebaixado a heurística antiga.

Na GDQ final, a continuação causal não é identificação direta de tempos. Ela é
feita no plano:

\[
\boxed{
z_\tau=\tau+i\nu_0t.
}
\]

### 3.3 \(\ln\mu\to\tau\) deve ser corrigido

Em `pt-br/notas/5/nota 5.2.md`, aparece o mapeamento:

\[
\ln\mu\to\tau.
\]

Isso não está correto dimensionalmente.

Como:

\[
[\tau]=L^2,
\]

\(\tau\) não pode ser igual a um logaritmo adimensional.

A correção é:

\[
\boxed{
\widehat\tau=\frac{\tau}{\ell_C^2},
\qquad
s=\log\widehat\tau.
}
\]

Então, a relação com RG deve ser escrita como:

\[
\boxed{
\frac{\partial}{\partial s}
=
\tau\frac{\partial}{\partial\tau}
}
\]

com:

\[
s=\log\left(\frac{\tau}{\ell_C^2}\right).
\]

Se for usada uma escala de energia/momento \(\mu\), a identificação deve ser do
tipo:

\[
\widehat\tau
\sim
\frac{1}{\mu^2\ell_C^2},
\]

e portanto:

\[
s
\sim
-2\log(\mu\ell_C).
\]

Logo:

\[
\boxed{
\tau\neq\ln\mu.
}
\]

### 3.4 \(\tau\) adimensional deve virar \(\widehat\tau\)

Em `pt-br/notas/4/nota 4.3.md`, aparece a expressão:

\[
\text{escala adimensional de fluxo }\tau.
\]

Isso conflita com:

\[
[\tau]=L^2.
\]

A correção é:

\[
\boxed{
\widehat\tau=\frac{\tau}{L_0^2}
}
\]

ou, usando a escala de Cartan:

\[
\boxed{
\widehat\tau=\frac{\tau}{\ell_C^2}.
}
\]

Assim, sempre que o texto quiser uma variável adimensional, deve escrever
\(\widehat\tau\), não \(\tau\).

### 3.5 O kernel \(\tau^{-2}\) deve ser corrigido para o bulk

Em `4-55.md`, aparece:

\[
\mathcal U\propto\tau^{-n/2}=\tau^{-2}
\quad
(n=4).
\]

Isso só seria correto se \(n\) fosse dimensão real \(4\).

Mas, na formulação final:

\[
n=4
\quad\text{é dimensão complexa},
\qquad
d=2n=8.
\]

Logo:

\[
\boxed{
K(\tau)\sim(4\pi\tau)^{-d/2}
=(4\pi\tau)^{-n}
=(4\pi\tau)^{-4}.
}
\]

Portanto, \(\tau^{-2}\) deve ser classificado como:

1. resultado antigo;
2. setor real 4D reduzido;
3. ou aproximação não-bulk.

Não deve ser usado como kernel fundamental do bulk.

## 4. O que deve ser descartado ou rebaixado

### 4.1 \(\tau\) como tempo físico direto

Descartar como definição fundamental:

\[
\boxed{
\tau=t.
}
\]

A relação correta é indireta:

\[
z_\tau=\tau+i\nu_0t.
\]

### 4.2 \(\tau\) como logaritmo de RG

Descartar:

\[
\boxed{
\tau=\ln\mu.
}
\]

Substituir por:

\[
s=\log\left(\frac{\tau}{\ell_C^2}\right).
\]

### 4.3 \(\partial_\tau\) como equação física local em \(N^4\)

Quando o texto escreve:

\[
\frac{\partial S_R}{\partial\tau}
\]

isso só é aceitável em uma formulação de fluxo/escala.

Para dinâmica física local em \(N^4\), o correto é:

\[
\frac{\partial S_R}{\partial t}.
\]

O mapa entre os dois setores deve passar por \(z_\tau\), não por identificação
direta.

## 5. Estrutura final recomendada para a Questão 6

A resposta final deve dizer:

### 5.1 Definição fundamental

\[
\boxed{
\tau\in\mathbb R_+
\text{ é parâmetro real de fluxo geométrico/difusivo.}
}
\]

\[
\boxed{
[\tau]=L^2.
}
\]

### 5.2 Relação com o tempo físico

\[
\boxed{
z_\tau=\tau+i\nu_0t,
\qquad
\nu_0=\frac{\hbar}{2m_0}.
}
\]

\[
\boxed{
\tau\neq t.
}
\]

### 5.3 Relação com RG

\[
\boxed{
\widehat\tau=\frac{\tau}{\ell_C^2},
\qquad
s=\log\widehat\tau.
}
\]

Se \(\mu\) for usada:

\[
\boxed{
s\sim-2\log(\mu\ell_C).
}
\]

### 5.4 Evolução em \(\tau\)

\[
\boxed{
\partial_\tau
\text{ é evolução de fluxo/escala, não evolução cronológica local.}
}
\]

### 5.5 Uso em janela efetiva

Dentro de uma janela física local:

\[
\boxed{
\tau=\text{constante de escala/regularização geométrica}.
}
\]

Entre janelas:

\[
\boxed{
\tau
\text{ pode variar como parâmetro RG geométrico.}
}
\]
