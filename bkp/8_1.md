# Questão 8 — Auditoria inicial sobre preservação da causalidade

## 1. Pergunta oficial

O arquivo `8-0.md` pergunta:

\[
\boxed{
\text{como a causalidade é preservada?}
}
\]

As perguntas obrigatórias são:

1. qual é o cone causal?
2. quais são os propagadores retardado, avançado e de Feynman?
3. por que usar metade avançado e metade retardado não permite sinalização
   para o passado?
4. como comutadores de observáveis separados espacialmente se comportam?
5. como o modelo trata experimentos de escolha retardada sem retrocausalidade
   observável?

O critério de resolução é:

\[
\boxed{
\text{demonstrar microcausalidade ou apresentar alternativa operacional
compatível com no-signalling.}
}
\]

## 2. Base já resolvida pelas questões anteriores

### 2.1 Cone causal

A Questão 2 fixou a métrica física:

\[
h_{\mu\nu}
=
q_{\mu\nu}
-2\frac{u_\mu u_\nu}{q^{-1}(u,u)}.
\]

Logo, o cone causal é:

\[
\boxed{
\mathcal C_h(p)
=
\{v\in T_pN:h(v,v)\le0\}.
}
\]

No setor plano:

\[
h=-dt^2+d\mathbf x^2.
\]

Assim:

\[
\boxed{
h(v,v)\le0
\Longleftrightarrow
|\mathbf v|\le1
}
\]

em unidades \(c=1\).

### 2.2 Cone comum dos campos

A Questão 2 também fixou que matéria escalar, torção, gauge e espinores
compartilham o cone de \(h\), desde que acoplados covariantemente à mesma
métrica.

O símbolo principal das equações fundamentais é:

\[
\boxed{
h^{\mu\nu}k_\mu k_\nu.
}
\]

Para Dirac:

\[
(\gamma^\mu k_\mu)^2
=
h^{\mu\nu}k_\mu k_\nu.
\]

Portanto, a velocidade frontal é controlada pelo cone de \(h\), não por
aproximações hidrodinâmicas truncadas.

### 2.3 Papel de Sudarshan

A Questão 4 fixou:

\[
G_{\rm sym}
=
\frac12(G_{\rm ret}+G_{\rm adv}).
\]

A Questão 7 fixou:

\[
\boxed{
\text{OS dá }(\mathcal H,H,U(t));
\qquad
\text{Sudarshan dá a prescrição causal em }z_\tau.
}
\]

Logo, a causalidade operacional não pode depender apenas de dizer que há uma
parte avançada. É preciso mostrar que a parte avançada não é um canal de
sinalização controlável.

## 4. Formulação causal correta

### 4.1 Propagador retardado

Para um operador hiperbólico \(P_h\) com símbolo principal:

\[
\sigma(P_h)=h^{\mu\nu}k_\mu k_\nu,
\]

o propagador retardado satisfaz:

\[
P_hG_{\rm ret}(x,y)=\delta_h(x,y),
\]

com suporte:

\[
\boxed{
\operatorname{supp}G_{\rm ret}(\cdot,y)\subset J_h^+(y).
}
\]

Esse é o propagador de resposta causal física.

### 4.2 Propagador avançado

O propagador avançado satisfaz:

\[
P_hG_{\rm adv}(x,y)=\delta_h(x,y),
\]

com suporte:

\[
\boxed{
\operatorname{supp}G_{\rm adv}(\cdot,y)\subset J_h^-(y).
}
\]

Ele aparece na formulação de contorno e na decomposição simétrica, mas não
deve ser interpretado como canal livre de envio de informação para o passado.

### 4.3 Propagador de Feynman

O propagador de Feynman é a prescrição temporal:

\[
\boxed{
G_F(x,y)
=
\langle\Omega|T\{\Phi(x)\Phi(y)\}|\Omega\rangle.
}
\]

No espaço de momentos plano:

\[
\boxed{
G_F(k)
=
\frac{i}{k_h^2-m^2+i\varepsilon}.
}
\]

onde:

\[
k_h^2=h^{\mu\nu}k_\mu k_\nu.
\]

### 4.4 Propagador causal/Pauli--Jordan

O comutador é controlado pela diferença:

\[
\boxed{
\Delta(x,y)
=
G_{\rm ret}(x,y)-G_{\rm adv}(x,y).
}
\]

Para campo escalar:

\[
\boxed{
[\Phi(x),\Phi(y)]
=
i\hbar\Delta(x,y).
}
\]

Como:

\[
\operatorname{supp}\Delta\subset J_h^+(y)\cup J_h^-(y),
\]

segue que, se \(x\) e \(y\) são espacialmente separados:

\[
\boxed{
[\Phi(x),\Phi(y)]=0.
}
\]

Essa é a microcausalidade.

### 4.5 Propagador simétrico de Sudarshan

A combinação:

\[
\boxed{
G_{\rm sym}
=
\frac12(G_{\rm ret}+G_{\rm adv})
}
\]

deve ser lida como:

\[
\boxed{
\text{parte simétrica/de contorno/constraint da solução, não propagador de
comutador nem canal de sinalização.}
}
\]

A resposta causal controlável a uma fonte externa local \(J\) deve ser
retardada:

\[
\boxed{
\delta\langle\mathcal O(x)\rangle
\propto
\int G_{\rm ret}(x,y)J(y)dV_y.
}
\]

Se \(x\notin J_h^+(y)\), a fonte em \(y\) não altera observáveis em \(x\).

## 5. Por que metade avançado + metade retardado não permite sinalização?

A formulação precisa deve ser:

1. o setor avançado não é uma fonte livre escolhível por um agente;
2. ele é fixado por condições globais de contorno, quantização e consistência
   da solução;
3. observáveis mensuráveis são calculados em \(\mathcal H\) reconstruído por
   OS, com Hamiltoniano positivo;
4. operações locais são representadas por álgebras locais;
5. álgebras associadas a regiões espacialmente separadas comutam.

Assim, para regiões \(O_1\) e \(O_2\) espacialmente separadas:

\[
\boxed{
[\mathcal A(O_1),\mathcal A(O_2)]=0.
}
\]

Uma operação local não seletiva em \(O_2\), com operadores de Kraus \(M_\alpha\)
tais que:

\[
\sum_\alpha M_\alpha^\dagger M_\alpha=1,
\]

não altera a estatística de observáveis \(A\in\mathcal A(O_1)\):

\[
\sum_\alpha
\operatorname{Tr}(M_\alpha\rho M_\alpha^\dagger A)
=
\operatorname{Tr}(\rho A).
\]

Isto usa:

\[
[A,M_\alpha]=0.
\]

Logo:

\[
\boxed{
\text{não há sinalização superluminal nem sinalização para o passado.}
}
\]

## 6. Tratamento correto de escolha retardada

O texto original pode ser aproveitado se reescrito assim:

1. a escolha tardia modifica o arranjo de medição;
2. isso muda quais observáveis serão correlacionados no registro final;
3. a descrição global pode ser resolvida por condições de contorno
   avançadas/retardadas;
4. porém os resultados marginais locais antes da comparação clássica não
   mudam;
5. o padrão de interferência ou informação de caminho aparece apenas depois da
   separação por contexto experimental e correlação dos dados.

Forma operacional:

\[
P(a|x)
=
\sum_bP(a,b|x,y)
\]

não depende da escolha tardia \(y\):

\[
\boxed{
P(a|x,y)=P(a|x,y')
}
\]

quando \(y\) é escolhido em região que não está no passado causal de \(a\).

Portanto, o modelo pode usar uma solução global tipo Sudarshan, desde que
respeite:

\[
\boxed{
\text{as marginais locais são independentes da escolha futura.}
}
\]
