# Questão 6 — Auditoria inicial de \(\tau\)

## 1. Pergunta oficial

O arquivo `6-0.md` pergunta:

\[
\boxed{
\text{o que é }\tau?
}
\]

A inconsistência atual é que \(\tau\) aparece como:

1. tempo de fluxo;
2. variável com dimensão de área;
3. tempo difusivo;
4. logaritmo adimensional de escala;
5. coordenada imaginária associada a \(t\).

A resposta aceitável exige escolher uma definição fundamental e fornecer mapas
dimensionais para os demais usos.

---

## 2. Definição fundamental proposta

A definição compatível com as Questões 2, 4 e 5 é:

\[
\boxed{
\tau\in\mathbb R_+
\text{ é o parâmetro real de fluxo geométrico/difusivo da GDQ, com dimensão }
L^2.
}
\]

Portanto:

\[
\boxed{
[\tau]=L^2.
}
\]

Ele não é, fundamentalmente, o tempo físico cronológico. Também não é,
fundamentalmente, o logaritmo adimensional da escala de renormalização.

Seu papel primário é parametrizar a resolução geométrica/difusiva do bulk e do
kernel de Perelman:

\[
K(\tau)\sim(4\pi\tau)^{-n},
\qquad
n=4.
\]

Assim, no bulk oficial:

\[
K(\tau)\sim(4\pi\tau)^{-4}.
\]

---

## 3. Relação com o tempo físico \(t\)

O tempo físico \(t\) tem dimensão:

\[
[t]=T.
\]

Como \(\tau\) tem dimensão \(L^2\), a combinação correta não pode ser:

\[
\tau+it.
\]

A combinação dimensionalmente correta, já consolidada na Questão 4, é:

\[
\boxed{
z_\tau=\tau+i\nu_0t.
}
\]

com:

\[
\boxed{
\nu_0=\frac{\hbar}{2m_0}.
}
\]

Como:

\[
[\nu_0]=\frac{L^2}{T},
\]

segue:

\[
[\nu_0t]=L^2,
\qquad
[z_\tau]=L^2.
\]

Portanto, \(t\) não é identificado com \(\tau\). A relação correta é:

\[
\boxed{
t
\longmapsto
i\nu_0t
\text{ dentro da variável causal complexa } z_\tau.
}
\]

Ou seja:

- \(\tau\) é a parte real difusiva/reológica;
- \(\nu_0t\) é a parte imaginária causal/cronológica com a mesma dimensão;
- \(z_\tau\) é a variável complexa integrada/continuada no contorno \(\gamma\).

---

## 4. Relação com a prescrição causal de Sudarshan

O contorno \(\gamma\) atua no plano complexo de:

\[
z_\tau=\tau+i\nu_0t.
\]

Assim:

\[
\boxed{
\gamma
\text{ não transforma }\tau\text{ em tempo físico; ele fixa a prescrição causal.}
}
\]

A causalidade de Sudarshan entra pela escolha de polos, ramos e contorno no
plano \(z_\tau\). O objeto causal é \(z_\tau\), não \(\tau\) isolado.

Isso evita a identificação incorreta:

\[
t=-i\tau.
\]

A continuação correta é dimensionalmente regulada por \(\nu_0\):

\[
i\nu_0t
\leftrightarrow
z_\tau-\tau.
\]

---

## 5. Relação com a escala de renormalização

Como \(\tau\) tem dimensão \(L^2\), ele não pode ser diretamente o logaritmo
adimensional de escala.

Para falar em escala RG, deve-se introduzir uma variável adimensional.

Usando a escala de Cartan \(\ell_C\), define-se:

\[
\boxed{
\widehat\tau=\frac{\tau}{\ell_C^2}.
}
\]

Então:

\[
[\widehat\tau]=1.
\]

Uma variável logarítmica admissível é:

\[
\boxed{
s=\log\widehat\tau
=
\log\left(\frac{\tau}{\ell_C^2}\right).
}
\]

Equivalente, se \(\mu\) é uma escala de energia/momento:

\[
\boxed{
\widehat\tau
\sim
\frac{1}{\mu^2\ell_C^2}
}
\]

ou:

\[
\boxed{
s
\sim
-2\log(\mu\ell_C).
}
\]

Logo:

\[
\boxed{
\tau
\neq
\log\mu.
}
\]

O mapa correto é:

\[
\tau
\longrightarrow
\widehat\tau=\frac{\tau}{\ell_C^2}
\longrightarrow
s=\log\widehat\tau.
\]

---

## 6. Relação com \(\epsilon\)

Na Questão 2 foi consolidada a relação:

\[
\widehat\tau=\frac{\tau}{\ell_C^2}.
\]

E, na janela de redução hidrodinâmica:

\[
\boxed{
\epsilon^2=2\widehat\tau
=
\frac{2\tau}{\ell_C^2}.
}
\]

Portanto:

\[
\boxed{
\epsilon
=
\sqrt{\frac{2\tau}{\ell_C^2}}.
}
\]

Essa relação não transforma \(\tau\) em campo dinâmico local. Ela define o
parâmetro efetivo \(\epsilon\) numa janela de escala.

Dentro de uma janela física local:

\[
\boxed{
\tau
\text{ e }
\epsilon
\text{ são tratados como parâmetros fixos.}
}
\]

Sua variação entre janelas é evolução de escala, não evolução temporal local.

---

## 7. A evolução em \(\tau\) é física ou auxiliar?

A resposta precisa é:

\[
\boxed{
\text{a evolução em }\tau\text{ é geométrica/de escala; não é evolução
cronológica local.}
}
\]

Ela é física no sentido estrutural: muda a resolução geométrica, o fluxo de
Perelman, o kernel e a janela efetiva.

Mas é auxiliar no sentido dinâmico local: ela não substitui o tempo físico
lorentziano \(t\) em \(N^4\).

Portanto:

| Objeto | Papel |
|---|---|
| \(t\) | tempo físico cronológico na camada \(N^4\) |
| \(\tau\) | parâmetro real de fluxo geométrico/difusivo, dimensão \(L^2\) |
| \(z_\tau\) | variável complexa causal \(z_\tau=\tau+i\nu_0t\) |
| \(\widehat\tau\) | escala adimensional \(\tau/\ell_C^2\) |
| \(s\) | escala logarítmica \(s=\log\widehat\tau\) |
| \(\mu\) | escala de energia/momento da linguagem RG |

---

## 8. Mapa de todos os usos de \(\tau\)

### 8.1 “Tempo de fluxo”

Aceitável, desde que entendido como:

\[
\boxed{
\text{tempo de fluxo geométrico, não tempo cronológico.}
}
\]

### 8.2 “Variável com dimensão de área”

Correto:

\[
\boxed{
[\tau]=L^2.
}
\]

### 8.3 “Tempo difusivo”

Aceitável, pois no kernel de calor o parâmetro de difusão tem dimensão de
comprimento ao quadrado:

\[
\partial_\tau u=\Delta u,
\qquad
[\Delta]=L^{-2},
\qquad
[\tau]=L^2.
\]

### 8.4 “Logaritmo adimensional de escala”

Incorreto se escrito diretamente.

A forma correta é:

\[
\boxed{
s=\log\left(\frac{\tau}{\ell_C^2}\right).
}
\]

### 8.5 “Coordenada imaginária associada a \(t\)”

Incorreto se escrito como \(t=-i\tau\) ou \(\tau+it\).

A forma correta é:

\[
\boxed{
z_\tau=\tau+i\nu_0t.
}
\]

---

## 9. Forma final recomendada

Sempre que \(\tau\) aparecer, o texto deve especificar em qual camada ele está
sendo usado.

### Camada geométrica

\[
\tau\in\mathbb R_+,
\qquad
[\tau]=L^2.
\]

### Camada causal

\[
z_\tau=\tau+i\nu_0t.
\]

### Camada de escala/RG

\[
\widehat\tau=\frac{\tau}{\ell_C^2},
\qquad
s=\log\widehat\tau.
\]

### Camada efetiva local

\[
\tau=\text{constante dentro da janela efetiva}.
\]
