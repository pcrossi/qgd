# Questão 7 — Auditoria inicial sobre emergência do tempo lorentziano

## 1. Pergunta oficial

O arquivo `7-0.md` pergunta:

\[
\boxed{
\text{como surge o tempo lorentziano?}
}
\]

As perguntas obrigatórias são:

1. quais funções de Schwinger são construídas?
2. elas satisfazem reflexão positiva?
3. há invariância euclidiana?
4. há simetria por permutação?
5. há propriedade de cluster?
6. qual Hamiltoniano lorentziano é reconstruído?
7. ele é autoadjunto e limitado inferiormente?

A resposta aceitável exige verificação das hipóteses de Osterwalder--Schrader
e reconstrução explícita.

A resposta não aceitável é:

\[
t=-i\tau
\]

ou:

\[
J^2=-1.
\]

---

## 2. Situação após as Questões 2 e 6

As questões anteriores já resolveram dois pontos importantes, mas eles não
fecham a Questão 7 sozinhos.

### 2.1 O que a Questão 2 resolveu

A Questão 2 mostrou que o bulk \(M\) permanece riemanniano e que a métrica
lorentziana física surge em \(N^4\) por uma construção constitutiva.

Com:

\[
X:N\to M,
\qquad
q=X^*g,
\qquad
u=X^*\omega,
\]

define-se:

\[
s=q^{-1}(u,u),
\qquad
s>0,
\]

e:

\[
\boxed{
h_{\mu\nu}
=
q_{\mu\nu}
-2\frac{u_\mu u_\nu}{s}.
}
\]

Num referencial adaptado:

\[
h=\operatorname{diag}(-1,1,1,1).
\]

Portanto:

\[
\boxed{
\operatorname{sign}(h)=(-,+,+,+).
}
\]

Isso resolve a assinatura lorentziana constitutiva.

Mas não prova, por si só, a reconstrução quântica lorentziana a partir de
correlações euclidianas.

### 2.2 O que a Questão 6 resolveu

A Questão 6 fixou:

\[
\boxed{
\tau\in\mathbb R_+,
\qquad
[\tau]=L^2.
}
\]

\[
\boxed{
z_\tau=\tau+i\nu_0t,
\qquad
\nu_0=\frac{\hbar}{2m_0}.
}
\]

\[
\boxed{
s=\log\left(\frac{\tau}{\ell_C^2}\right).
}
\]

Logo:

\[
\boxed{
\tau\neq t,
\qquad
t\neq-i\tau.
}
\]

Isso resolve a dimensão e a relação causal entre \(\tau\) e \(t\).

Mas também não prova, sozinho, reflexão positiva nem reconstrução OS.

## 4. O que pode ser aproveitado

### 4.1 Crítica à rotação de Wick clássica

O capítulo 03 mostra corretamente que a rotação:

\[
t\to -i\tau
\]

é insuficiente quando há:

1. termos de fronteira;
2. transformações de calibre não triviais;
3. fronteiras topológicas;
4. dinâmica geométrica;
5. ruído estocástico/fractal.

Esse material é aproveitável como motivação para não usar Wick ingênuo.

### 4.2 Contorno causal de Sudarshan

O texto usa:

\[
G_{\rm sym}
=
\frac12(G_{\rm ret}+G_{\rm adv}).
\]

Essa estrutura é aproveitável como prescrição causal da continuação
lorentziana.

Mas, para a Questão 7, ela deve ser reinterpretada assim:

\[
\boxed{
\gamma
\text{ não substitui OS; ele escolhe a continuação causal após OS.}
}
\]

Ou seja, Sudarshan ajuda a escolher os valores de contorno e a projeção física,
mas não é automaticamente uma prova de reflexão positiva.

### 4.3 Cancelamento de termos exatos

O uso:

\[
\oint_\gamma dF=0
\]

é aproveitável para termos exatos, desde que:

1. \(F\) seja monovalorada;
2. o domínio não atravesse cortes de ramo;
3. as singularidades estejam controladas;
4. \(\gamma\) seja admissível.

Mas isso não equivale a reflexão positiva OS.

### 4.4 Métrica lorentziana constitutiva

A construção:

\[
h_{\mu\nu}
=
q_{\mu\nu}
-2\frac{u_\mu u_\nu}{q^{-1}(u,u)}
\]

deve ser usada na Questão 7 como a métrica lorentziana final sobre a qual os
campos reconstruídos propagam.

Mas a reconstrução do espaço de Hilbert e do Hamiltoniano ainda precisa das
funções de Schwinger.

## 5. O que deve ser corrigido ou rejeitado

### 5.1 Rejeitar \(t=-i\tau\)

A Questão 6 já eliminou:

\[
t=-i\tau.
\]

Na Questão 7, a continuação correta deve passar por:

\[
z_\tau=\tau+i\nu_0t.
\]

### 5.2 Rejeitar \(J^2=-1\) como prova de tempo

A estrutura complexa:

\[
J^2=-1
\]

é necessária para a geometria complexa, mas não prova:

1. reflexão positiva;
2. existência de Hamiltoniano;
3. espectro positivo;
4. causalidade lorentziana;
5. unitariedade.

Logo:

\[
\boxed{
J^2=-1
\text{ não responde a Questão 7.}
}
\]

### 5.3 Corrigir \(\mathcal T=\tau+it\)

Qualquer variável temporal complexa deve ser escrita como:

\[
\boxed{
z_\tau=\tau+i\nu_0t.
}
\]

### 5.4 Separar duas noções de “lorentzianização”

Há duas questões distintas:

1. **assinatura lorentziana constitutiva**, já resolvida pela Questão 2;
2. **reconstrução quântica lorentziana**, exigida pela Questão 7.

A Questão 7 trata da segunda.

## 6. Como deve ser resolvida a Questão 7

Para fechar a Questão 7, a teoria precisa introduzir uma camada OS
compatível com a GDQ.

### 6.1 Definir funções de Schwinger

Para campos efetivos \(\Phi_a\) em uma fatia euclidiana de \(N\), definir:

\[
S_n^{a_1\cdots a_n}(x_1,\ldots,x_n)
=
\frac{1}{Z_E}
\int
\Phi_{a_1}(x_1)\cdots\Phi_{a_n}(x_n)
e^{-S_E[\Phi;g,f,B]}
\mathcal D\Phi.
\]

Aqui \(S_E\) deve ser o funcional euclidiano efetivo induzido pela GDQ numa
janela fixa de \(\tau\), com:

\[
\tau=\text{parâmetro de escala fixo na janela}.
\]

### 6.2 Definir a reflexão temporal

Escolher uma coordenada euclidiana \(x_E^0\) compatível com a forma-relógio
\(u\).

Definir:

\[
\Theta x_E=(-x_E^0,\mathbf x).
\]

Para campos:

\[
(\Theta\Phi)(x)
=
\eta_\Phi\,\Phi(\Theta x)^*
\]

com sinal/fator \(\eta_\Phi\) dependente do tipo de campo.

### 6.3 Provar reflexão positiva

Para qualquer funcional \(F\) suportado em \(x_E^0>0\), exigir:

\[
\boxed{
\langle \Theta F\,F\rangle_E\ge0.
}
\]

Em termos de funções de Schwinger:

\[
\sum_{i,j}
\bar c_i c_j
S_{m_i+m_j}
(\Theta X_i,Y_j)
\ge0.
\]

Esse é o ponto central da Questão 7.

### 6.4 Verificar invariância euclidiana

No fundo plano efetivo, exigir invariância sob:

\[
E(4)=\mathbb R^4\rtimes SO(4).
\]

Em background curvo, substituir por invariância covariante local ou por uma
versão OS local numa carta normal.

### 6.5 Verificar simetria por permutação

Para campos bosônicos:

\[
S_n(\ldots,x_i,x_{i+1},\ldots)
=
S_n(\ldots,x_{i+1},x_i,\ldots).
\]

Para férmions, usar antissimetria/estrutura graduada.

### 6.6 Verificar cluster

Exigir:

\[
\lim_{|a|\to\infty}
S_{m+n}(X,Y+a)
=
S_m(X)S_n(Y).
\]

Isso garante unicidade do vácuo no setor reconstruído.

### 6.7 Reconstruir o espaço de Hilbert

Construir o espaço pré-Hilbert dos funcionais positivos:

\[
\mathcal D_+
=
\{F:\operatorname{supp}F\subset x_E^0>0\}.
\]

Produto interno:

\[
(F,G)
=
\langle \Theta F\,G\rangle_E.
\]

Quocientar os vetores nulos:

\[
\mathcal N=\{F:(F,F)=0\}.
\]

Completar:

\[
\boxed{
\mathcal H
=
\overline{\mathcal D_+/\mathcal N}.
}
\]

### 6.8 Reconstruir o Hamiltoniano

Translações euclidianas positivas definem um semigrupo:

\[
T_E(a),\qquad a\ge0.
\]

Pela positividade OS:

\[
T_E(a)
=
e^{-aH}.
\]

Então:

\[
\boxed{
H
=
-\left.\frac{d}{da}T_E(a)\right|_{a=0^+}.
}
\]

Pelo teorema de Hille--Yosida/Stone:

\[
\boxed{
H=H^\dagger,
\qquad
H\ge0.
}
\]

Esse \(H\) é o Hamiltoniano lorentziano reconstruído.

### 6.9 Continuar para tempo físico

Depois da reconstrução OS, a evolução lorentziana é:

\[
U(t)=e^{-itH/\hbar}.
\]

A variável causal da GDQ entra como compatibilidade:

\[
z_\tau=\tau+i\nu_0t.
\]

Mas a unitariedade vem de:

\[
H=H^\dagger.
\]

Não vem de escrever \(t=-i\tau\).
