# Note — Numerical classification

The minimal classification is:

| Class | Criterion |
|---|---|
| direct evaluation | no comparison used to build the formula |
| convergence | explicit variation of mesh or tolerance |
| consistency | analytical limit or symmetry recovered |
| reverse engineering | target used to infer parameter |
| fit/calibration | parameter calibrated and declared |
| comparison | formula frozen prior to data |
| blind prediction | no target and with frozen parameters |

Every output must declare its class.
