# 27.9 — Self-contained scripts of the protocol

This chapter includes protocol scripts, not new physical solvers.

See [[scripts/README]].

| Script | Function |
|---|---|
| `generate_example_manifest.py` | generates a minimal GDQ script manifest |
| `classify_result.py` | exemplifies result classification |
| `numerical_status_table.py` | consolidates the status of the main numerical blocks |
| `hessian_block_projector_schur.py` | demonstrates the common Hessian, constraints, physical projector, and Schur complement block |
| `gdq_reduced.py` | reduced library for DtN, Schur, quadratic response, detector, and two-alternative density |
| `verify_gdq_reduced.py` | verifies the analytical identities of the reduced library |

These scripts serve as models for future chapters and benchmarks.
