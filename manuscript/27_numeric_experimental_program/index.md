# 27 — Numerical and experimental program

This chapter transforms the accumulated experience into a reproducible protocol. GDQ already has a common calculation chain. The next step is to apply it uniformly to real backgrounds, real apparatuses, and independent data.

Central rule:

$$
\boxed{
\text{every numerical calculation must state exactly what it calculates and what it does not.}
}
$$
