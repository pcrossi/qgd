# 27.4 — Minimal validations and numerical classification

A numerical result should only be promoted when it passes explicit validations.

Minimal validations:

1. analytical limit;
2. mesh refinement;
3. charge or flux conservation;
4. positivity or gap;
5. self-adjointness or symmetric discretization;
6. stability under tolerance;
7. comparison with the source-free case;
8. sensitivity to boundary conditions;
9. frozen experimental comparison;
10. reproducible report in Markdown.

Mandatory classification:

| Class | Usage |
|---|---|
| direct evaluation | formula already derived |
| convergence | mesh/tolerance |
| consistency | known limit |
| reverse engineering | target used to obtain parameter |
| fit/calibration | parameter explicitly calibrated |
| phenomenological comparison | confrontation after the formula is frozen |
| blind prediction | no target used prior to comparison |

It is not acceptable to adjust a coefficient and then call it derived. It is also not acceptable to omit poor outputs when they exclude an ansatz.
