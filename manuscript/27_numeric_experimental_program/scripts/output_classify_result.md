# Output — result classifier

Classification: documentary tool / rule example.

| scenario | classification |
|---|---|
| formula already derived, no target data | consistency test |
| mesh refined against analytical limit | strong prediction or strong metrological test |
| parameter inferred from target | reverse engineering or fit |
| formula frozen and subsequent comparison | controlled phenomenological comparison |
| no target, multiple observables, measured apparatus | strong prediction or strong metrological test |

## Rule

If the experimental target entered before the formula, do not call it a prediction.
