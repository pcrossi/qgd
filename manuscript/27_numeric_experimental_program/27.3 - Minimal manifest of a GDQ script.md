# 27.3 — Minimal manifest of a GDQ script

Every new numerical or symbolic script must declare:

| Field | Question it answers |
|---|---|
| equation or functional | what is being evaluated? |
| background $\Phi_*$ | in which solution or approximation? |
| domain | which interval, manifold, or mesh? |
| boundary | which boundary conditions? |
| constraints | which charges, fluxes, and normalizations? |
| operator | which Hessian, Jacobi, or DtN? |
| projector | which modes were removed? |
| source/apparatus | what is external data? |
| observable | what comes out of the calculation? |
| universal parameters | which come from the theory? |
| apparatus parameters | which come from the experiment? |
| numerical parameters | mesh, tolerance, solver |
| data usage | did the target enter prior to the comparison? |
| classification | evaluation, convergence, adjustment, or prediction? |

The manifest avoids two confusions:

$$
\boxed{
\text{apparatus parameter}
\ne
\text{universal constant;}
}
$$

$$
\boxed{
\text{data used as boundary condition}
\ne
\text{data used to adjust internal coefficient.}
}
$$

The script [[scripts/generate_example_manifest.py]] generates an example of a self-contained manifest.
