# 27.8 — Criterion for strong comparisons

A comparison can be called strong if:

1. the formula was frozen prior to the comparison;
2. the apparatus parameters were measured independently;
3. the experimental error was declared;
4. the numerical uncertainty is smaller than the discrepancy;
5. the boundary condition sensitivity was reported;
6. the same set of parameters works on more than one observable.

If these conditions are not satisfied, the comparison must be called:

$$
\boxed{
\text{phenomenological compatibility or proof of concept.}
}
$$

This does not diminish the value of the result. It simply prevents the manuscript from confusing a developmental stage with a final metrological conclusion.
