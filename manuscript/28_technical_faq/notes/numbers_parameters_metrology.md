# Numbers, parameters, and metrology

The strength criterion of a numerical comparison is:

$$
\text{derivation}
\to
\text{frozen parameters}
\to
\text{calculation}
\to
\text{comparison}.
$$

If the experimental target was used to choose internal coefficients, the result must be labeled as reverse engineering or calibration.

The physics of units also needs to be separated. The theory can predict ratios:

$$
\theta_{AB}
=
\frac{A}{B}.
$$

To convert this into a dimensional unit, it is necessary to choose a metrological ruler:

$$
A_{\rm physical}
=
\theta_{AB}B_{\rm calibration}.
$$

This is not a special weakness of GDQ. It is the normal structure of any physical theory: units are conventions of comparison.

## Rule for metrological tables

Every comparison table must make explicit:

1. calculated value;
2. accepted value or reference used;
3. absolute error when the unit is important;
4. relative error when the observable is a ratio;
5. calculation status.

If an accepted value was used to calibrate a unit ruler, it cannot be used again as independent proof. If it entered only after the formula was frozen, the comparison is informative.
