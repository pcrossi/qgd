# 17. Proton, Neutron, and Baryonic Structure

This chapter organizes the baryonic sector of GDQ. A baryon will not be treated as a point particle or as an ontological set of fundamental quarks. The description used here is geometric:

$$
\boxed{
\text{baryon = glued trimodal solution with global integer charge and surface torsion.}
}
$$

The basic object is a Ricci–Bismut solution with three confined stomata:

$$
\mathfrak G_B
=
\{
\mathcal F_a,\Psi_{ab},\mathcal A_{ab},B_{ab},g_B,f_B
\}_{a,b=1}^{3}.
$$

The effective cycle used to extract invariants is:

$$
\mathcal C_B
\simeq
T^5_{\rm braided}
\times
S^3_{\rm hol}.
$$

This cycle is an auxiliary spectral/cosmological domain. It does not replace the official local bulk:

$$
M=\mathbb R^4\times T^4.
$$
