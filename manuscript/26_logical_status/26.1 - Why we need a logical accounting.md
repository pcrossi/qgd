# 26.1 — Why we need a logical accounting

A broad theory faces two risks. The first is to confuse a technical hypothesis
with an axiom. The second is to confuse a good number with a proof.

GDQ only remains controlled if each statement is classified:

| Class | Meaning |
|---|---|
| axiom | fundamental input of the theory |
| definition | fixed internal convention |
| derivation | variational or algebraic consequence |
| conditional theorem | result demonstrated under declared domain/boundary |
| effective reduction | operational limit comparable to the laboratory |
| numerical evidence | reproducible test of a chain |
| phenomenological comparison | confrontation with accepted data, without becoming a proof |
| future program | metrological, covariant, or experimental extension |

The physical point is simple: all real physics has a domain, boundary, and
preparation condition. Declaring these conditions does not weaken the theory.
The problem would be to hide them.

The reading rule of this chapter is:

$$
\boxed{
\text{conditional does not mean arbitrary; it means the domain has been declared.}
}
$$

And:

$$
\boxed{
\text{effective reduction is not a new ontology; it is a controlled projection of GDQ.}
}
$$
