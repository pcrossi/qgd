# Note — Reductions and numerical evidence

A script can fulfill different roles:

| Class | Example |
|---|---|
| direct evaluation | calculate an already derived formula |
| convergence test | vary mesh/tolerance |
| consistency test | recover known limit |
| phenomenological comparison | compare with accepted data |
| blind prediction | freeze parameters before data |
| reverse engineering | choose parameter by target |

In the manuscript, incorporated scripts should belong to preservable classes:
direct evaluations, consistency tests, final reductions, and explicitly
classified comparisons.

Failed attempts may be historically important, but they should not make up the
positive narrative when they have already been replaced by a better construction.
