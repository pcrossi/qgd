# 26.5 — Effective reductions and numerical evidence

An effective reduction is valid when it preserves action, domain, boundary, and
physical projector.

$$
\boxed{
\text{official action}
\to
\text{background}
\to
\text{physical Hessian}
\to
\text{reduced operator}
\to
\text{observable}.
}
$$

Examples already incorporated into the manuscript:

| Sector | Reduced result |
|---|---|
| well and oscillator | standard spectra in the flat limit |
| tunneling | proper length saturation without superluminal front |
| Casimir | ideal pressure by effective determinant |
| molecular rotor | $J(J+1)$ spectrum and centrifugal distortion |
| Stern--Gerlach | axis selected by boundary/apparatus |
| double slit | coherence controlled by detector impedance |
| Aharonov--Bohm | local/topological holonomy of the connection |
| Sagnac | clock holonomy on rotating boundary |
| hydrogen | Dirac--Bismut operator and boundary corrections |
| alpha | Schur--Riesz and surface evanescent channel |
| cosmology | global boundary and horizon scales |
