# Scripts of Chapter 01

| Script | Role | Classification |
|---|---|---|
| `comparar_kernel_wiener_feynman.py` | Compares Wiener positivity with Feynman oscillation. | Pedagogical consistency test |
| `verificar_termo_osmotico_bohm.py` | Verifies the osmotic identity that generates the Bohm term. | Symbolic-numerical verification |
| `verificar_difusao_variavel_ito.py` | Verifies the Itô expansion for $D=\nu_0\Omega^{-1}$ and the variable osmotic velocity. | Symbolic-numerical verification |

These scripts do not introduce new physical parameters. They preserve, in executable form, the elementary calculations used in the introductory chapter.
