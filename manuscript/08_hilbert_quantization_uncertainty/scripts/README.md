# Optional scripts — Chapter 8

These scripts are illustrations of consistency. They do not replace the sectorial reconstruction of the Hilbert space nor the topological proof of Wallstrom.

## Scripts

| Script | Output | Function |
|---|---|---|
| `test_gaussian_uncertainty.py` | `output_test_gaussian_uncertainty.md` | Verifies $\Delta x\,\Delta p=\hbar/2$ in minimum Gaussians. |
| `verify_wallstrom_circulation.py` | `output_verify_wallstrom_circulation.md` | Shows that regular $S^1\to S^1$ maps have integer winding and exemplifies integer Chern flux. |
| `verify_hilbert_positivity.py` | `output_verify_hilbert_positivity.md` | Toy model of positive semidefinite form and quotient by zero norm. |
| `verify_operational_hilbert.py` | `output_verify_operational_hilbert.md` | Toy model of the physical quotient, states, observables, unitary evolution, and tensor composition. |
| `verify_unitary_physical_time.py` | `output_verify_unitary_physical_time.md` | Toy model of unitariety in $t$, Euclidean contraction, and decay in a projected sector. |
