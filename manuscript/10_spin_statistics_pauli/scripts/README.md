# Scripts — Chapter 10

The scripts in this directory are symbolic/didactic tests.

| Script | Goal | Classification |
|---|---|---|
| `verify_rotation_su2.py` | Verify $U(2\pi)=-I$ and $U(4\pi)=I$. | Symbolic test. |
| `verify_residue_hopf_cauchy.py` | Verify the Cauchy integral with residue $1/2$ on the normal loop to the stoma. | Symbolic-numerical test. |
| `verify_exchange_holonomy.py` | Verify $-1$ holonomy for half-circulation. | Topological/symbolic test. |
| `verify_car_pauli.py` | Verify exclusion in finite exterior algebra. | Algebraic test. |
