# Saída — triplet Hopf--Bismut

## Base de 2-formas

Ordem usada: `['12', '13', '14', '23', '24', '34']`.

## Formas hipercähler

- `Omega_1 = 1 e12 +1 e34`
- `Omega_2 = 1 e13 -1 e24`
- `Omega_3 = 1 e14 +1 e23`

## Teste de autodualidade

- `||*Omega_1 - Omega_1|| = 0.000e+00`
- `||*Omega_2 - Omega_2|| = 0.000e+00`
- `||*Omega_3 - Omega_3|| = 0.000e+00`
- `||*Omega_1 + Omega_1|| = 2.828427`
- `||*Omega_2 + Omega_2|| = 2.828427`
- `||*Omega_3 + Omega_3|| = 2.828427`

## Gram da base normalizada Sigma_i^+ = Omega_i/sqrt(2)

```text
[[1. 0. 0.]
 [0. 1. 0.]
 [0. 0. 1.]]
```

Conclusão: o triplet de Hopf é auto-dual na orientação complexa padrão e a base normalizada é ortonormal.
