# Scripts — Capítulo 10

Os scripts deste diretório são testes simbólicos/didáticos.

| Script | Objetivo | Classificação |
|---|---|---|
| `verificar_rotacao_su2.py` | Verificar $U(2\pi)=-I$ e $U(4\pi)=I$. | Teste simbólico. |
| `verificar_residuo_hopf_cauchy.py` | Verificar a integral de Cauchy com resíduo $1/2$ no laço normal ao estômato. | Teste simbólico-numérico. |
| `verificar_holonomia_troca.py` | Verificar holonomia $-1$ para meia-circulação. | Teste topológico/simbólico. |
| `verificar_car_pauli.py` | Verificar a exclusão em álgebra exterior finita. | Teste algébrico. |
