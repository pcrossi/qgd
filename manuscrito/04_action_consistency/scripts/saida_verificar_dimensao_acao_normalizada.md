# Saída — dimensão da ação normalizada

## Classificação

Teste simbólico dimensional. Não é previsão física.

## Convenção

$\Lambda_C$ é tratado como número de corte adimensional nas coordenadas normalizadas.

## Tabela dimensional

| Quantidade | Dimensão |
|---|---|
| $\mathcal R$ | `L^-2` |
| $\tau$ | `L^2` |
| $\tau\mathcal R$ | `1` |
| $\tau|\nabla f|^2$ | `1` |
| $(f+\bar f)/2-n$ | `1` |
| $\mathcal U$ em $n=4$ | `L^-8` |
| $dV_g$ | `L^8` |
| $d\tau/\tau$ | `1` |
| $\hbar/\Lambda_C^2$ | `hbar^1` |
| ação total | `hbar^1` |

## Veredito

A checagem passou: a ação tem dimensão de $\hbar$.

Esta saída não determina a escala física $\ell_C$, $k_C$ ou $E_C$.
