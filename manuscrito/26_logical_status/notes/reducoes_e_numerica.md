# Nota — Reduções e evidência numérica

Um script pode cumprir papéis diferentes:

| Classe | Exemplo |
|---|---|
| avaliação direta | calcular uma fórmula já derivada |
| teste de convergência | variar malha/tolerância |
| teste de consistência | recuperar limite conhecido |
| comparação fenomenológica | comparar com dado aceito |
| previsão cega | congelar parâmetros antes do dado |
| engenharia inversa | escolher parâmetro pelo alvo |

No manuscrito, os scripts incorporados devem ser das classes preserváveis:
avaliações diretas, testes de consistência, reduções finais e comparações
explicitamente classificadas.

Tentativas falhas podem ser importantes historicamente, mas não devem compor a
narrativa positiva quando já foram substituídas por uma construção melhor.
