# 26.2 — Axiomas centrais e dados de problema

Os axiomas centrais da GDQ devem permanecer poucos.

| Item | Status |
|---|---|
| ação oficial | axioma dinâmico |
| classe Hermitiana/Bismut | axioma geométrico |
| contorno causal $\gamma$ | dado causal fundamental do problema |
| classe topológica admissível | dado estrutural |
| condições globais e de bordo | dados físicos do problema |
| escalas metrológicas não derivadas | calibração, não dinâmica nova |

A ação oficial é:

$$
\mathcal{S}_{\mathrm{GDQ}}
=
\int_{\gamma}
\left[
\int_{\mathcal{M}_{\mathbb C}}
\frac{\hbar}{\Lambda_C^2}
\left[
\tau\left(
\mathcal R
+
g^{\mu\bar\nu}
\partial_\mu f
\partial_{\bar\nu}\bar f
\right)
+
\frac{f+\bar f}{2}
-n
\right]
\mathcal U
\sqrt{\det g}
\,d^{2n}z
\right]
\frac{d\tau}{\tau}.
$$

Ela não deve ser substituída por Einstein--Hilbert, Yang--Mills, Dirac, Pauli
ou Modelo Padrão. Essas estruturas podem aparecer como reduções efetivas,
comparações ou linguagens auxiliares.

No manuscrito reestruturado, $\Lambda_C$ é tratado como número de corte em
coordenadas normalizadas pela escala de Cartan. Símbolos dimensionais como
$k_C$, $\ell_C$ e $E_C$ são usados quando for necessário restaurar unidades.

Fontes, sondas e termos de bordo não alteram a ação fundamental. Eles entram
como dados externos do problema ou como termos de interface derivados pelo
princípio variacional.
