# 26.1 — Por que precisamos de uma contabilidade lógica

Uma teoria ampla corre dois riscos. O primeiro é confundir uma hipótese técnica
com um axioma. O segundo é confundir um bom número com uma prova.

A GDQ só permanece controlada se cada afirmação for classificada:

| Classe | Significado |
|---|---|
| axioma | entrada fundamental da teoria |
| definição | convenção interna fixa |
| derivação | consequência variacional ou algébrica |
| teorema condicional | resultado demonstrado sob domínio/contorno declarados |
| redução efetiva | limite operacional comparável ao laboratório |
| evidência numérica | teste reprodutível de uma cadeia |
| comparação fenomenológica | confronto com dado aceito, sem virar prova |
| programa futuro | extensão metrológica, covariante ou experimental |

O ponto físico é simples: toda física real tem domínio, contorno e condição de
preparação. Declarar essas condições não enfraquece a teoria. O problema seria
ocultá-las.

A regra de leitura deste capítulo é:

$$
\boxed{
\text{condicional não significa arbitrário; significa que o domínio foi declarado.}
}
$$

E:

$$
\boxed{
\text{redução efetiva não é nova ontologia; é projeção controlada da GDQ.}
}
$$
