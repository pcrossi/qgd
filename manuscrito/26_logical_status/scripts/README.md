# Scripts — Capítulo 26

Este capítulo não introduz novos cálculos físicos. Os scripts abaixo são
checagens de inventário lógico e consolidação de comparações já preservadas.

| Script | Saída | Função |
|---|---|---|
| `inventario_logico.py` | `saida_inventario_logico.md` | classificar axiomas, definições, condicionais, reduções e programas futuros |
| `comparacoes_preservadas.py` | `saida_comparacoes_preservadas.md` | consolidar números já incorporados ao manuscrito |

## Execução

```bash
python3 manuscrito/26_logical_status/scripts/inventario_logico.py
python3 manuscrito/26_logical_status/scripts/comparacoes_preservadas.py
```
