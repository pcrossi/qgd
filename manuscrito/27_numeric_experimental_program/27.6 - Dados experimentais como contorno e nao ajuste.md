# 27.6 — Dados experimentais como contorno e não ajuste

Dados experimentais são necessários. O ponto é quando eles entram.

Um dado pode entrar como contorno independente:

$$
B_{\rm app},\quad
L_{\rm cavidade},\quad
T_{\rm detector},\quad
R_H,\quad
H_0.
$$

Esses são dados do aparelho, do material ou do universo observado. Eles
definem o problema.

O que não é permitido é escolher um coeficiente interno depois da comparação e
chamá-lo de derivado.

$$
\boxed{
\text{dado experimental como contorno/aparelho}
\ne
\text{dado experimental usado para ajustar a teoria.}
}
$$

Prioridades de dados:

1. CODATA para constantes de referência;
2. PDG para massas, larguras, momentos e parâmetros de mistura;
3. NUBASE/AME/ENSDF para dados nucleares;
4. SPARC/RAR para curvas galácticas;
5. Planck/BAO/SNe para cosmologia;
6. espectroscopia de hidrogênio eletrônico e muônico;
7. especificações reais de Stern--Gerlach, detectores, solenoides, fibras,
   anéis e cavidades.
