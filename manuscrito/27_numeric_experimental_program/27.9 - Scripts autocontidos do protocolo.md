# 27.9 — Scripts autocontidos do protocolo

Este capítulo inclui scripts de protocolo, não novos solvers físicos.

Ver [[scripts/README]].

| Script | Função |
|---|---|
| `gerar_manifesto_exemplo.py` | gera um manifesto mínimo de script GDQ |
| `classificar_resultado.py` | exemplifica a classificação de resultados |
| `tabela_status_numerico.py` | consolida status dos blocos numéricos principais |
| `bloco_hessiana_projetor_schur.py` | demonstra o bloco comum Hessiana, vínculos, projetor físico e complemento de Schur |
| `gdq_reduced.py` | biblioteca reduzida DtN, Schur, resposta quadrática, detector e densidade de duas alternativas |
| `verificar_gdq_reduced.py` | verifica as identidades analíticas da biblioteca reduzida |

Esses scripts servem como modelos para próximos capítulos e benchmarks.
