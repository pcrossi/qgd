# 27.8 — Critério para comparações fortes

Uma comparação pode ser chamada forte se:

1. a fórmula foi congelada antes da comparação;
2. os parâmetros do aparelho foram medidos independentemente;
3. o erro experimental foi declarado;
4. a incerteza numérica é menor que a discrepância;
5. a sensibilidade a contorno foi informada;
6. o mesmo conjunto de parâmetros funciona em mais de um observável.

Se essas condições não forem satisfeitas, a comparação deve ser chamada de:

$$
\boxed{
\text{compatibilidade fenomenológica ou prova de conceito.}
}
$$

Isso não diminui o valor do resultado. Apenas impede que o manuscrito confunda
estágio de desenvolvimento com conclusão metrológica final.
