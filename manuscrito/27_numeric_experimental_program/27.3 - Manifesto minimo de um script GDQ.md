# 27.3 — Manifesto mínimo de um script GDQ

Todo script numérico ou simbólico novo deve declarar:

| Campo | Pergunta que responde |
|---|---|
| equação ou funcional | o que está sendo avaliado? |
| background $\Phi_*$ | em qual solução ou aproximação? |
| domínio | qual intervalo, variedade ou malha? |
| contorno | quais condições de bordo? |
| vínculos | quais cargas, fluxos e normalizações? |
| operador | qual Hessiana, Jacobi ou DtN? |
| projetor | quais modos foram removidos? |
| fonte/aparelho | o que é dado externo? |
| observável | o que sai do cálculo? |
| parâmetros universais | quais vêm da teoria? |
| parâmetros de aparelho | quais vêm do experimento? |
| parâmetros numéricos | malha, tolerância, solver |
| uso de dados | o alvo entrou antes da comparação? |
| classificação | avaliação, convergência, ajuste ou previsão? |

O manifesto evita duas confusões:

$$
\boxed{
\text{parâmetro de aparelho}
\ne
\text{constante universal;}
}
$$

$$
\boxed{
\text{dado usado como contorno}
\ne
\text{dado usado para ajustar coeficiente interno.}
}
$$

O script [[scripts/gerar_manifesto_exemplo.py]] gera um exemplo de manifesto
autocontido.
