# Nota — Classificação numérica

A classificação mínima é:

| Classe | Critério |
|---|---|
| avaliação direta | nenhuma comparação usada para construir a fórmula |
| convergência | variação explícita de malha ou tolerância |
| consistência | limite analítico ou simetria recuperada |
| engenharia inversa | alvo usado para inferir parâmetro |
| ajuste/calibração | parâmetro calibrado e declarado |
| comparação | fórmula congelada antes do dado |
| previsão cega | sem alvo e com parâmetros congelados |

Toda saída deve declarar a classe.
