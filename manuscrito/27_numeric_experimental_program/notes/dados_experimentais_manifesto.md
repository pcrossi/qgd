# Nota — Manifesto de dados experimentais

Um manifesto de dados deve declarar:

1. fonte;
2. versão ou data;
3. observável;
4. unidade;
5. incerteza;
6. se o dado foi usado como contorno ou como alvo;
7. em que etapa entrou no cálculo.

Sem isso, uma comparação não pode ser classificada como forte.
