# Scripts — Capítulo 3

Estes scripts são verificações simbólicas ou ilustrações pedagógicas ligadas ao
Capítulo 3. Eles não são previsões físicas e não substituem as provas do texto.

## Scripts

1. `verificar_z_tau_dimensional.py`
   - Classificação: teste simbólico dimensional.
   - Verifica que $z_\tau=\tau+i\nu_0t$ é homogêneo em dimensão de área.
   - Saída: `saida_verificar_z_tau_dimensional.md`.

2. `verificar_integral_forma_exata.py`
   - Classificação: ilustração de contorno.
   - Compara a integral de uma forma exata regular num ciclo fechado com uma
     forma fechada de período não trivial.
   - Saída: `saida_verificar_integral_forma_exata.md`.

3. `verificar_pareamento_realidade_contorno.py`
   - Classificação: teste simbólico de pareamento conjugado.
   - Ilustra que pares conjugados no contorno contribuem com soma real.
   - Saída: `saida_verificar_pareamento_realidade_contorno.md`.

## Uso

```bash
python3 verificar_z_tau_dimensional.py
python3 verificar_integral_forma_exata.py
python3 verificar_pareamento_realidade_contorno.py
```
