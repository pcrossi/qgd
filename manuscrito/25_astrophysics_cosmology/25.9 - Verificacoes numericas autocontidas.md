# 25.9 — Verificações numéricas autocontidas

Os scripts deste capítulo ficam em [[scripts/README]]. Eles foram escritos como
verificadores autocontidos, sem depender das auditorias históricas.

| Script | Verificação |
|---|---|
| `buraco_negro_reduzido.py` | core regular, horizontes, Hessiana reduzida e Page toy |
| `buraco_negro_pipeline_reduzido.py` | sela radial, TOV efetivo, virial, Hessiana por blocos e consistência de Schur |
| `cosmologia_escalas_gdq.py` | $\rho_\Lambda$, $a_0$ e escalas de horizonte |
| `eletrofraca_raio_proton.py` | $v_{\rm GDQ}$, $W/Z$ reduzido e $r_p^{\rm surf}$ |

Esses scripts preservam as versões finais/reduzidas, não tentativas
infrutíferas. Cada saída Markdown informa a classificação científica.
