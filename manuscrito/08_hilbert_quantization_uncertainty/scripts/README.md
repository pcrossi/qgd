# Scripts opcionais — Capítulo 8

Estes scripts são ilustrações de consistência. Eles não substituem a
reconstrução setorial do espaço de Hilbert nem a prova topológica de
Wallstrom.

## Scripts

| Script | Saída | Função |
|---|---|---|
| `testar_incerteza_gaussianas.py` | `saida_testar_incerteza_gaussianas.md` | Verifica $\Delta x\,\Delta p=\hbar/2$ em gaussianas mínimas. |
| `verificar_wallstrom_circulacao.py` | `saida_verificar_wallstrom_circulacao.md` | Mostra que mapas $S^1\to S^1$ regulares têm enrolamento inteiro e exemplifica fluxo de Chern inteiro. |
| `verificar_positividade_hilbert.py` | `saida_verificar_positividade_hilbert.md` | Toy model de forma positiva semidefinida e quociente por norma nula. |
| `verificar_hilbert_operacional.py` | `saida_verificar_hilbert_operacional.md` | Toy model do quociente físico, estados, observáveis, evolução unitária e composição tensorial. |
| `verificar_unitariedade_tempo_fisico.py` | `saida_verificar_unitariedade_tempo_fisico.md` | Toy model de unitariedade em $t$, contração euclidiana e decaimento em setor projetado. |
