# Scripts do Capítulo 23

| Script | Saída | Função |
|---|---|---|
| `poco_oscilador_reducao.py` | `saida_poco_oscilador_reducao.md` | Verifica poço ideal, oscilador harmônico e índices de Morse reduzidos. |
| `poco_impedancia_gdq.py` | `saida_poco_impedancia_gdq.md` | Compara poço infinito, Robin/DtN e barreira finita. |
| `hartman_saturacao.py` | `saida_hartman_saturacao.md` | Avalia a saturação do comprimento próprio evanescente. |
| `casimir_ideal.py` | `saida_casimir_ideal.md` | Calcula pressão ideal de Casimir para separações típicas. |
| `casimir_zeta_derivacao.py` | `saida_casimir_zeta_derivacao.md` | Verifica simbolicamente o coeficiente universal $720/240$ do Casimir ideal. |
| `rotor_molecular_reduzido.py` | `saida_rotor_molecular_reduzido.md` | Calcula espectro de rotor e distorção centrífuga para CO como comparação. |
| `rotor_distorcao_symbolic.py` | `saida_rotor_distorcao_symbolic.md` | Deriva simbolicamente o termo $D=\hbar^4/(2\mu^3\omega_e^2R_0^6)$. |

Todos os scripts são autocontidos, comentados e geram saída Markdown. Eles são
testes de redução, convergência ou comparação fenomenológica, não substituem a
Hessiana completa da ação oficial.
