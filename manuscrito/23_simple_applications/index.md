# 23. Aplicações simples e testes de redução

Este capítulo reúne problemas elementares onde a GDQ deve recuperar operadores
conhecidos quando o background é plano, estacionário e com contornos simples.

O objetivo não é usar esses exemplos como prova independente da teoria. Eles
servem para verificar a cadeia:

$$
\mathcal S_{\rm GDQ}
\to
\Phi_\ast
\to
K_{\rm phys}
\to
P_{\rm phys}K_{\rm phys}P_{\rm phys}
\to
\text{operador reduzido}
\to
\text{observável}.
$$
