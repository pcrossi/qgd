# 28 — FAQ técnica e objeções recorrentes

Este capítulo reúne respostas curtas para objeções que aparecem repetidamente
quando a GDQ é lida a partir de linguagens externas: mecânica quântica
operacional, Modelo Padrão, geometrização de Perelman, teoria de campos,
metrologia experimental e computação numérica.

O FAQ não substitui as demonstrações do manuscrito. Ele funciona como camada de
orientação:

$$
\boxed{
\text{o corpo do manuscrito demonstra; este capítulo classifica objeções.}
}
$$
