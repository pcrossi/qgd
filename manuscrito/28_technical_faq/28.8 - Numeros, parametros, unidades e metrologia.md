# 28.8 — Números, parâmetros, unidades e metrologia

Números bons não substituem uma derivação.

A regra de leitura é:

$$
\boxed{
\text{concordância numérica reforça uma cadeia; não cria a cadeia.}
}
$$

Um resultado numérico é forte quando:

1. a equação foi derivada antes;
2. o domínio foi declarado;
3. o contorno foi fixado;
4. os parâmetros foram congelados antes da comparação;
5. a malha ou tolerância foi refinada;
6. o alvo experimental não foi usado para escolher coeficientes internos.

Caso contrário, o resultado deve ser classificado como benchmark,
compatibilidade fenomenológica, engenharia inversa controlada ou prova de
conceito.

Também é preciso separar unidades de razões. Nenhuma teoria física prevê o
número “MeV”, “metro” ou “quilograma” sem convenção metrológica. O que uma
teoria fundamental pode prever são relações adimensionais:

$$
\frac{m_\mu}{m_e},
\qquad
\frac{m_\tau}{m_e},
\qquad
\alpha,
\qquad
\frac{r_p}{\ell_C},
\qquad
\frac{v_{\rm EW}}{M_p}.
$$

Depois de escolhida uma escala de referência, as demais escalas podem ser
expressas como razões geométricas.

Algumas comparações preservadas no manuscrito são:

| Observável | Valor GDQ reduzido | Referência numérica congelada no script | Erro relativo |
|---|---:|---:|---:|
| $\alpha^{-1}$ | $137.036082448164$ | $137.035999$ | $+6.09\times10^{-7}$ |
| $m_\mu/m_e$ | $206.768593470629$ | $206.768283$ | $+1.50\times10^{-6}$ |
| $m_\tau/m_e$ | $3477.446405098382$ | $3477.15$ | $+8.52\times10^{-5}$ |
| $v_{\rm EW}$ | $246.111195996\,\mathrm{GeV}$ | $246.21965\,\mathrm{GeV}$ | $-0.044048\%$ |
| $r_p$ | $0.840778765432\,\mathrm{fm}$ | $0.84087\,\mathrm{fm}$ | $-0.010850\%$ |
| $\nu_{\rm hfs}^{\rm H}$ | $1420405718.790905\,\mathrm{Hz}$ | $1420405751.768\,\mathrm{Hz}$ | $-32.977095\,\mathrm{Hz}$ |
| $\rho_\Lambda$ | $6.136532599384\times10^{-27}\,\mathrm{kg/m^3}$ | $5.842445930612\times10^{-27}\,\mathrm{kg/m^3}$ | $+5.033622\%$ |

Esses números devem ser lidos no status correto. Alguns são resultados
estruturais reduzidos; outros são estimativas metrológicas condicionais. O
manuscrito deve preservar essa diferença.

O script regenera somente a aritmética da tabela; ele não substitui as
derivações dos capítulos temáticos. As fontes bibliográficas, versões e datas
das referências numéricas devem acompanhar a edição citável final. Até essa
inserção, “referência” significa precisamente o valor congelado no script, não
uma alegação de atualização automática ao padrão metrológico mais recente.
