# Saída — matriz de status do FAQ

| Objeção | Resposta curta | Status | Ação recomendada |
|---|---|---|---|
| A ação muda para bater números? | Não. Mudam background, contorno, fonte, vínculo, projetor e observável. | definição metodológica | preservar a ação oficial e declarar dados externos |
| A GDQ é o Modelo Padrão renomeado? | Não. O Modelo Padrão aparece apenas como redução operacional setorial. | redução efetiva | não inverter a cadeia dedutiva |
| Perelman 3D foi aplicado em 8D? | A aplicação é setorial por fatoração; backgrounds mistos exigem Hessiana completa. | teorema condicional | indicar domínio produto ou misto |
| Born foi assumido? | Born é operacional no Hilbert físico; o evento individual exige aparelho. | fechado estruturalmente | separar probabilidade de mecanismo de registro |
| Bell/no-signalling está provado? | A geometria do emaranhamento está formulada; aparelhos reais são extensão. | programa operacional futuro | calcular marginais com impedâncias reais |
| Fantasmas/BRST são ontologia? | Não. São linguagem auxiliar de auditoria de quociente, quando usados. | classificação ontológica | usar Tr_phys log K_phys como objeto intrínseco |
| Bons números provam tudo? | Não. Eles reforçam cadeias derivadas, mas não substituem derivação. | critério numérico | classificar comparação e congelar parâmetros |
| Massas absolutas são previstas do nada? | Não. Unidades exigem calibração; a teoria mira razões adimensionais. | metrologia | separar régua dimensional de razão geométrica |
