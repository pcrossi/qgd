# 28.9 — Resultados condicionais e como não reabrir problemas

Um resultado condicional não é um resultado fraco. Ele é uma afirmação com
hipóteses explícitas.

Na GDQ, muitos resultados têm a forma:

$$
\text{se } H_1,\ldots,H_k \text{ valem, então } R \text{ segue da ação oficial.}
$$

Isso é diferente de ajuste. O que não se pode fazer é apagar as hipóteses.

Exemplos de leitura correta:

| Tema | Status conservador |
|---|---|
| hierarquia leptônica | teorema condicional no domínio intrínseco/produto; backgrounds warped/mistos são extensão |
| três gerações | condicional à classe de três centros, equilíbrio torsional e colagem APS/Bismut |
| problema do sinal | fechado estruturalmente no mecanismo geométrico e em benchmarks reduzidos; algoritmo universal é futuro |
| constantes absolutas | fechadas por calibração metrológica; alvo fundamental são razões adimensionais |
| Navier--Stokes | retirado do núcleo; pode ficar como aplicação futura |
| Bell/no-signalling | emaranhamento geométrico formulado; aparelhos reais exigem prova operacional |

O critério para não reabrir um problema é perguntar: a nova objeção ataca uma
hipótese já declarada ou revela uma contradição interna?

Se apenas pede metrologia mais fina, ela não reabre o resultado estrutural. Se
mostra que uma hipótese usada é incompatível com a ação oficial, então reabre.
