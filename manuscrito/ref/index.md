# Referências

Esta pasta reúne as referências bibliográficas e as notas de fontes utilizadas
na edição reestruturada do manuscrito.

## Política do acervo

Cada referência citável possui uma ficha pública em um arquivo Markdown desta
pasta. A ficha contém os dados bibliográficos, links oficiais e uma nota sobre
seu uso no manuscrito. As citações dos capítulos apontam para essas fichas, e
não para cópias integrais ou para páginas de OCR.

PDFs, OCRs completos e extrações por página podem ser mantidos localmente em
pastas homônimas para conferência. Esse acervo de trabalho não integra a
versão publicada no Git. Quando uma afirmação depender de uma página
específica, a página permanece indicada no rótulo da nota, por exemplo
`Autor ano, p. 10`, enquanto o link conduz à ficha bibliográfica.
