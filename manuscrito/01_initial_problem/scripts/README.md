# Scripts do Capítulo 01

| Script | Papel | Classificação |
|---|---|---|
| `comparar_kernel_wiener_feynman.py` | Compara a positividade de Wiener com a oscilação de Feynman. | Teste pedagógico de consistência |
| `verificar_termo_osmotico_bohm.py` | Verifica a identidade osmótica que gera o termo de Bohm. | Verificação simbólico-numérica |
| `verificar_difusao_variavel_ito.py` | Verifica a expansão de Itô para $D=\nu_0\Omega^{-1}$ e a velocidade osmótica variável. | Verificação simbólico-numérica |

Esses scripts não introduzem novos parâmetros físicos. Eles preservam, de
forma executável, os cálculos elementares usados no capítulo introdutório.
