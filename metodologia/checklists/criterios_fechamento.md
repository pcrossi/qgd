# Checklist — critérios de fechamento

## 1. Antes de declarar fechado

- [ ] A ação oficial foi preservada.
- [ ] O background foi classificado.
- [ ] O domínio foi definido.
- [ ] Os contornos foram definidos.
- [ ] Os vínculos foram listados.
- [ ] O projetor físico foi definido ou justificado.
- [ ] A Hessiana física foi identificada.
- [ ] A fonte/aparelho foi declarada como externa ou derivada.
- [ ] O observável foi extraído sem pós-ajuste.
- [ ] Os parâmetros universais foram separados dos parâmetros de aparelho.
- [ ] O resultado numérico foi classificado.
- [ ] Houve teste de convergência ou limite analítico.
- [ ] As limitações foram registradas.

## 2. Status correto

Usar:

- fechado;
- fechado estruturalmente;
- fechado condicionalmente;
- parcialmente resolvido;
- aberto;
- programa futuro.

## 3. Regras negativas

Não declarar fechado se:

1. um parâmetro foi escolhido usando o alvo;
2. a fonte foi inserida como operador quântico importado;
3. a métrica foi assumida evoluída sem solver;
4. o detector foi representado por fator fenomenológico não derivado;
5. não há domínio;
6. não há contorno;
7. não há observável definido.
