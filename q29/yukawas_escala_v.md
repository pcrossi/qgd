# Q29 — Bloco 4 — Yukawas, massas fermiônicas e escala \(v\)

## 1. Objetivo

Organizar como férmions adquirem massa e como a escala eletrofraca deve ser
derivada na GDQ.

---

## 2. Yukawas efetivos

No limite efetivo:

\[
\mathcal L_Y
=
-y_d\bar Q_L\Phi d_R
-y_u\bar Q_L\tilde\Phi u_R
-y_e\bar L_L\Phi e_R
+{\rm h.c.}
\]

com:

\[
\tilde\Phi=i\sigma_2\Phi^*.
\]

Após:

\[
\langle\Phi\rangle
=
\frac1{\sqrt2}
\begin{pmatrix}0\\v\end{pmatrix},
\]

temos:

\[
\boxed{
m_f=\frac{y_fv}{\sqrt2}.
}
\]

---

## 3. Yukawas na GDQ

Na GDQ, \(y_f\) não deve ser parâmetro livre. Deve ser integral de sobreposição:

\[
\boxed{
y_{ij}
=
\mathcal N_Y
\int_{\mathcal I}
\langle
\psi_{L,i},
\Phi_{\rm EW}
\psi_{R,j}
\rangle
d\mu_g.
}
\]

Onde:

1. \(\psi_{L,i}\) e \(\psi_{R,j}\) são modos do operador de Dirac--Bismut;
2. \(\Phi_{\rm EW}\) é o modo de ordem;
3. \(d\mu_g\) é a medida interna efetiva;
4. \(\mathcal N_Y\) é normalização cinética.

---

## 4. Escala \(v\)

Fenomenologicamente:

\[
v=(\sqrt2G_F)^{-1/2}\approx246{,}22\,{\rm GeV}.
\]

Na GDQ, a definição estrutural é:

\[
\boxed{
v^2
=
\mathcal N_\Phi
\int_{\mathcal I}
|\Phi_{\rm EW}^{(0)}|^2d\mu_g.
}
\]

Equivalentemente, pela expansão variacional:

\[
\boxed{
v^2=-2a_2/a_4.
}
\]

Essas duas expressões devem coincidir quando o modo estiver canonically
normalizado.

---

## 5. \(G_F\)

O acoplamento de Fermi é efetivo:

\[
\boxed{
\frac{G_F}{\sqrt2}
=
\frac{g^2}{8m_W^2}
=
\frac{1}{2v^2}.
}
\]

Logo:

\[
\boxed{
G_F=\frac{1}{\sqrt2v^2}.
}
\]

Na GDQ, derivar \(G_F\) é equivalente a derivar \(v\).

---
