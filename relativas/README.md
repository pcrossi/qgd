# Questões relativas ao texto legado

Esta pasta registra questões cuja função é auditar ou marcar limitações do
manuscrito original, dos scripts antigos ou de validações legadas.

Ela não é a pasta canônica das questões resolvidas da GDQ. Para resultados
dedutivos consolidados, usar `questoes/`, `memory.md`, `brain/` e os
documentos finais correspondentes.

## Critério de uso

Uma questão entra aqui quando:

1. aponta um erro, circularidade ou limitação do texto original;
2. não exige modificar o original porque o manuscrito será reescrito;
3. já foi resolvida, superada ou reclassificada por documentos posteriores;
4. serve como lembrete editorial para não reaproveitar uma validação fraca.

## Status geral

As questões 63--69 ficam classificadas como:

$$
\boxed{
\text{auditorias relativas ao legado; não reabrem a teoria vigente.}
}
$$

Elas devem orientar a reescrita, não comandar novas mudanças no texto original.
