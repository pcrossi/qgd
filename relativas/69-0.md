# Questão 69

## 69. A alegação atual deve ser retirada? (Navier--Stokes)

Sim.

## Decisão vigente

$$
\boxed{
\text{retirar a alegação de resolução de Navier--Stokes do núcleo da GDQ.}
}
$$

Navier--Stokes deve permanecer como programa matemático separado, não como
validação central da teoria.

## Motivo

A estimativa uniforme em $H^s$ depende de controlar:

$$
\int_0^T\|\nabla u\|_{L^\infty}\,dt,
$$

que é precisamente o tipo de controle cuja ausência permite blow-up. Usar esse
controle como hipótese equivale a introduzir por trás o critério de
regularidade que deveria ser demonstrado.

## O que seria necessário para reabrir

Para reabrir a alegação, seria necessário demonstrar, sem circularidade:

1. estimativa uniforme independente de $\epsilon$;
2. ausência de hipótese equivalente ao critério de regularidade;
3. convergência forte suficiente para o termo não linear;
4. recuperação da incompressibilidade;
5. controle global para dados gerais;
6. revisão por especialistas independentes.

## Status

Esta questão fica apenas como auditoria relativa ao legado. A GDQ pode, no
futuro, sugerir uma rota regularizada/projetiva para Navier--Stokes, mas isso
não deve ser apresentado como resultado atual.
