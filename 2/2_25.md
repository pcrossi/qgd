# Modelo GDQ v2.25 — Redução Exata sobre Bulk Local Plano

Este documento executa as **Tarefas A, B e C** exigidas no parecer `2_24.md`. Abandonamos temporariamente a curvatura de K3 e construímos um modelo local de teste plano para derivar de forma analiticamente exata a dinâmica da imersão, o vínculo do lapse e as equações do dilaton.

---

## 1. Setup do Modelo Local Plano (Tarefa A)

Para garantir que o pullback seja espacialmente redondo de forma exata, definimos o bulk de teste local como:

$$\mathcal{M}_{\text{teste}} = \mathbb{R}^4 \times S^1$$

com a métrica produto euclidiana plana standard:

$$g = \delta_{AB} dy^A \otimes dy^B + R_0^2 d\theta \otimes d\theta$$

onde $y^A \in \mathbb{R}^4$ e $\theta \in [0, 2\pi[$. Sendo a métrica plana, os símbolos de Christoffel do bulk são identicamente nulos:

$$\Gamma^A_{BC}(g) = 0$$

Definimos a imersão dinâmica $i: N \to \mathcal{M}_{\text{teste}}$ de $N = \mathbb{R} \times S^3$ por:

$$i(t, \hat{x}) = \left( b(t)\hat{x},\; \varphi(t) \right)$$

onde $\hat{x} \in S^3 \subset \mathbb{R}^4$ é a parametrização da esfera unitária. O pullback $q = i^*g$ é calculado exatamente:

- Componentes espaciais: $q_{ij} = g_{AB} \partial_i (b \hat{x}^A) \partial_j (b \hat{x}^B) = b(t)^2 \gamma_{0ij}$ (exato, sem correções de curvatura).
- Componente temporal: $q_{tt} = \dot{b}(t)^2 + R_0^2 \dot{\varphi}(t)^2$.
- Componentes mistas: $q_{ti} = 0$.

Com $\lambda_f = \lambda(t) dt$, o vínculo constitutivo $h_{\mu\nu} = q_{\mu\nu} - \lambda_{f\mu}\lambda_{f\nu}$ fornece:

$$h_{ij} = b(t)^2 \gamma_{0ij}$$

$$h_{tt} = \dot{b}(t)^2 + R_0^2 \dot{\varphi}(t)^2 - \lambda(t)^2 \equiv -N(t)^2$$

onde $N(t) = \sqrt{\lambda(t)^2 - \dot{b}(t)^2 - R_0^2 \dot{\varphi}(t)^2} > 0$ é o lapso lorentziano.

## 2. A Equação da Imersão Completa (Tarefa B)

A variação da ação em relação à coordenada da imersão $i^C(x)$ com backgrounds fixos ($\delta_{AB}, R_0, \lambda_f$) é obtida variando:

$$\mathcal{S}_i = -\int_N d^4x \sqrt{-h} e^{-f} \Lambda^{\mu\nu} q_{\mu\nu}$$

Variando $q_{\mu\nu} = g_{AB} \partial_i i^A \partial_j i^B$ e realizando a integração por partes rigorosa, a equação de movimento para a imersão torna-se exatamente:

$$\boxed{
\Lambda^{\mu\nu} \left( \nabla^h_\mu \partial_\nu i^A + \Gamma^A_{BC}(g) \partial_\mu i^B \partial_\nu i^C - \partial_\mu f \partial_\nu i^A \right) + \left( \nabla^h_\mu \Lambda^{\mu\nu} \right) \partial_\nu i^A = 0
}
\tag{I}$$

Como o bulk $\mathcal{M}_{\text{teste}}$ é plano, a conexão $\Gamma(g)$ é nula. A equação reduz-se a:

$$\Lambda^{\mu\nu} \left( \nabla^h_\mu \partial_\nu i^A - \partial_\mu f \partial_\nu i^A \right) + \left( \nabla^h_\mu \Lambda^{\mu\nu} \right) \partial_\nu i^A = 0$$

### 2.1 Mudança para Tempo Próprio e o Vínculo de Lapse

Definimos a parametrização pelo tempo próprio $d\tau = N(t) dt$. A métrica em $N$ é:

$$h = -d\tau^2 + b(\tau)^2 \gamma_0$$

A relação entre as derivadas temporais é $\dot{b} = N b$ e $\dot{\varphi} = N \varphi'$ (onde $'= d/d\tau$). O vínculo do lapse em tempo próprio torna-se:

$$N^2 = \lambda^2 - N^2 b'^2 - N^2 R_0^2 \varphi'^2 \implies \boxed{ N^2 = \frac{\lambda^2}{1 + b'^2 + R_0^2 \varphi'^2} }$$

## 3. Redução Cosmológica e Solução do Sistema

Para o ansatz FLRW, assumimos que o multiplicador de Lagrange no shell é diagonal e compatível com a simetria espacial:

$$\Lambda^\tau_i = 0, \qquad \Lambda^j_i = \Lambda_s \delta^j_i, \qquad \Lambda^\tau_\tau = \Lambda_0$$

Calculamos a equação da imersão (I) na direção radial euclidiana $i^r = b(\tau)$:

1. **Termo 1:** $\Lambda^{\mu\nu} \nabla^h_\mu \partial_\nu i^r = \Lambda^{00} \left( b'' - \Gamma^0_{00} b' \right) + \Lambda^{ij} \left( \partial_i \partial_j b - \Gamma^\mu_{ij} \partial_\mu b \right)$.
   Como a métrica é diagonal, $\Gamma^0_{00} = 0$, e $\Gamma^0_{ij} = b b' \gamma_{0ij}$.
   Portanto, $\Lambda^{\mu\nu} \nabla^h_\mu \partial_\nu i^r = -\Lambda_0 b'' + \Lambda_s \frac{\gamma_0^{ij}}{b^2} ( - b b' \gamma_{0ij} ) = -\Lambda_0 b'' - 3 \Lambda_s \frac{b'}{b}$.

2. **Termo 2:** $-\Lambda^{\mu\nu} \partial_\mu f \partial_\nu i^r = \Lambda_0 f' b'$.

3. **Termo 3:** $(\nabla^h_\mu \Lambda^{\mu\nu}) \partial_\nu i^r = -(\nabla^h_\mu \Lambda^{\mu 0}) b' = -\left( \partial_\tau \Lambda_0 + 3 H_c \Lambda_0 - 3 H_c \Lambda_s \right) b'$.

Somando todos os termos e dividindo por $-1$:

$$\Lambda_0 b'' + 3 \Lambda_s \frac{b'}{b} - \Lambda_0 f' b' + \left( \partial_\tau \Lambda_0 + 3 H_c \Lambda_0 - 3 H_c \Lambda_s \right) b' = 0$$

Como $H_c = b'/b$, o termo $3 \Lambda_s \frac{b'}{b}$ cancela-se com $-3 H_c \Lambda_s b'$. A equação radial reduz-se a:

$$\Lambda_0 b'' - \Lambda_0 f' b' + \left( \partial_\tau \Lambda_0 + 3 H_c \Lambda_0 \right) b' = 0$$

Como a equação métrica dita $\Lambda_{\mu\nu} = -A E_{\mu\nu}$, temos:
- $\Lambda_0 = - \Lambda^\tau_\tau = A E^\tau_\tau = A \left( 3 H_c^2 + 3 \frac{1}{b^2} - 3 H_c f' \right)$
- A identidade de conservação com backgrounds fixos dita $\nabla_\mu \Lambda^{\mu\nu} = \mathcal{F}^\nu$ (força externa de Noether devido aos backgrounds).

### 3.1 A Integração Correta do Sistema Reduzido

Se assumirmos um regime onde a variação espacial do multiplicador $\nabla_\mu \Lambda^{\mu\nu}$ é desprezível ou contrabalançada na direção temporal pelo dilaton, a equação radial reduz-se ao atrator dinâmico:

$$b'' - f' b' = 0 \implies \frac{b''}{b'} = f'$$

A integração correta (corrigindo o sinal de `2_23.md`) é:

$$\ln |b'| = f + c_0 \implies b'(\tau) = C_0 e^{f(\tau)}$$

Substituindo $u = e^{-f/2}$, temos $e^f = 1/u^2$, logo:

$$\boxed{ b'(\tau) = \frac{C_0}{u(\tau)^2} }$$

### 3.2 Análise de Positividade e Sturm

A equação do dilaton $u'' + 3 H_c u' + \frac{R}{4} u = 0$ com $R = 6 \left( \frac{b''}{b} + H_c^2 + \frac{1}{b^2} \right)$ torna-se:

$$u'' + 3 \frac{b'}{b} u' + \frac{3}{2} \left( \frac{b''}{b} + \frac{b'^2 + 1}{b^2} \right) u = 0$$

Substituindo $b'' = b' f' = -2 \frac{u'}{u} b'$:

$$u'' + 3 \frac{b'}{b} u' + \frac{3}{2} \left( -2 \frac{u' b'}{u b} + \frac{b'^2 + 1}{b^2} \right) u = 0$$

$$u'' + \frac{3}{2} \frac{b'^2 + 1}{b^2} u = 0$$

Substituindo $b' = C_0 / u^2$:

$$\boxed{ u'' + \frac{3}{2} \frac{C_0^2 u^{-4} + 1}{b(\tau)^2} u = 0 } \implies \boxed{ u'' + \frac{3}{2 b^2} u + \frac{3 C_0^2}{2 b^2 u^3} = 0 }$$

Esta é uma equação do tipo **Ermakov-Pinney**!

## 4. Resolução da Equação de Ermakov-Pinney (Tarefa C)

A equação de Ermakov-Pinney com coeficiente dependente do tempo possui a forma geral:

$$u'' + \Omega^2(\tau) u + \frac{\beta^2}{u^3} = 0$$

com $\Omega^2(\tau) = \frac{3}{2 b^2} > 0$ e $\beta^2 = \frac{3 C_0^2}{2 b^2} > 0$.

### 4.1 Regularidade Global e Evitação de Zeros

Diferente do oscilador linear $u'' + \Omega^2 u = 0$ (que sempre cruza o zero quando $\Omega^2 > 0$ por Sturm), a equação de Ermakov-Pinney possui uma **barreira de potencial singular** em $u=0$ devido ao termo repulsivo $1/u^3$.

Se as condições iniciais satisfizerem $u(0) > 0$, a solução **nunca pode atingir zero** para tempos finitos, pois a energia efetiva diverge quando $u \to 0$:

$$V_{\text{efetivo}}(u) = \frac{1}{2}\Omega^2 u^2 + \frac{\beta^2}{2 u^2} \to +\infty \quad \text{se } u \to 0$$

Portanto:
1. **O dilaton $f = -2\ln u$ é globalmente regular** (não possui singularidades) para todo o domínio onde a solução existir.
2. A taxa de expansão $b' = C_0 / u^2$ permanece sempre positiva e finita.
