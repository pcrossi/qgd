# Modelo GDQ v2.36 — Retrificação Final e Consistência Geométrica Completa

Este documento corrige a componente angular da equação da imersão e recalcula a projeção normal no bulk plano de teste $\mathbb{R}^4 \times S^1$, conforme exigido pela auditoria em `2_35.md`. Demonstramos que a inclusão do termo de Hessiana angular ausente restabelece a consistência matemática interna e prova a equivalência exata entre a projeção normal e a dinâmica radial no shell.

---

## 1. Convenção de Índices e Ortogonalidade no Bulk

Definimos a métrica do bulk plano como:

$$g_{\text{bulk}} = \delta_{AB} dy^A dy^B + R_0^2 d\theta \otimes d\theta$$

Seja o vetor velocidade contravariante da imersão $T^M = (b' n^A, \varphi')$ em relação à base coordenada $(\partial_A, \partial_\theta)$. O vetor normal contravariante $\mathcal{N}^M = (\mathcal{N}^A, \mathcal{N}^\theta)$ satisfaz a condição de ortogonalidade:

$$g_{MN} T^M \mathcal{N}^N = 0 \implies b' \delta_{AB} n^A \mathcal{N}^B + R_0^2 \varphi' \mathcal{N}^\theta = 0$$

Escolhendo $\mathcal{N}^A = R_0^2 \varphi' n^A$ e $\mathcal{N}^\theta = -b'$, a norma quadrada do vetor normal é:

$$\|\mathcal{N}\|^2 = R_0^2 \left( R_0^2 \varphi'^2 + b'^2 \right)$$

Esta escolha é bem-definida em todo ponto regular onde $b'^2 + \varphi'^2 \neq 0$. A projeção contravariante da equação da imersão $\mathcal{E}^M = (\mathcal{E}^r n^A, \mathcal{E}^\theta)$ é dada por:

$$g_{MN} \mathcal{E}^M \mathcal{N}^N = R_0^2 \left( \varphi' \mathcal{E}^r - b' \mathcal{E}^\theta \right)$$

Assim, a condição de projeção normal $\mathcal{E}_{\perp} = 0$ equivale a:

$$\boxed{ \varphi' \mathcal{E}^r - b' \mathcal{E}^\theta = 0 } \tag{N}$$

---

## 2. Inclusão da Hessiana Espacial na Componente Angular

A componente angular contravariante $\mathcal{E}^\theta$ da equação da imersão contém a contribuição da Hessiana espacial de $\Theta = \varphi(\tau)$, a qual foi omitida nas versões anteriores:

$$\Lambda^{ij} \nabla_i \partial_j \varphi = \Lambda^{ij} \left( \partial_i \partial_j \varphi - \Gamma^M_{ij} \partial_M \varphi \right) = \Lambda^{ij} \left( -\Gamma^\tau_{ij} \varphi' \right)$$

Na métrica FLRW com tempo próprio $\tau$, temos $\Gamma^\tau_{ij} = b b' \gamma_{0ij}$. Usando $\Lambda^{ij} = P_\Lambda h^{ij} = P_\Lambda b^{-2} \gamma_0^{ij}$, a contração resulta em:

$$\Lambda^{ij} \nabla_i \partial_j \varphi = P_\Lambda b^{-2} \gamma_0^{ij} \left( -b b' \gamma_{0ij} \varphi' \right) = -3 P_\Lambda \frac{b'}{b} \varphi'$$

A componente angular contravariante completa é, portanto:

$$\boxed{ \mathcal{E}^\theta = \rho_\Lambda \varphi'' - 3 P_\Lambda \frac{b'}{b} \varphi' - f' \rho_\Lambda \varphi' + \varphi' (\nabla_\mu \Lambda^{\mu\tau}) } \tag{1}$$

Usando a expressão para a divergência $\nabla_\mu \Lambda^{\mu\tau} = \rho_\Lambda' + 3 \frac{b'}{b}(\rho_\Lambda + P_\Lambda)$, a componente angular reduz-se a:

$$\mathcal{E}^\theta = \rho_\Lambda \varphi'' + \left( \rho_\Lambda' + 3 \frac{b'}{b} \rho_\Lambda - f' \rho_\Lambda \right) \varphi'$$

Esta componente é perfeitamente consistente com a primeira integral circular obtida na Seção 6 de `2_27.md`:

$$\mathcal{E}^\theta = 0 \quad\Longleftrightarrow\quad \frac{d}{d\tau} \left( b^3 e^{-f} \rho_\Lambda \varphi' \right) = 0 \implies \boxed{ b^3 e^{-f} \rho_\Lambda \varphi' = J_0 } \tag{2}$$

## 3. Projeção Normal Corrigida e Cancelamento de Pressão

Substituindo a componente radial $\mathcal{E}^r$ e a angular completa $\mathcal{E}^\theta$ na projeção normal (N):

$$\varphi' \mathcal{E}^r - b' \mathcal{E}^\theta = \varphi' \left[ \rho_\Lambda b'' - 3 P_\Lambda \frac{1+b'^2}{b} - f' \rho_\Lambda b' + b' (\nabla_\mu \Lambda^{\mu\tau}) \right] - b' \left[ \rho_\Lambda \varphi'' - 3 P_\Lambda \frac{b'}{b} \varphi' - f' \rho_\Lambda \varphi' + \varphi' (\nabla_\mu \Lambda^{\mu\tau}) \right]$$

Os termos dilatônicos ($f'$) e de divergência se cancelam identicamente off-shell. Os termos de pressão combinam-se para fornecer:

$$- 3 P_\Lambda \varphi' \frac{1+b'^2}{b} + 3 P_\Lambda \varphi' \frac{b'^2}{b} = -3 P_\Lambda \frac{\varphi'}{b}$$

Portanto, a equação normal corrigida é:

$$\boxed{ \rho_\Lambda \left( \varphi' b'' - b' \varphi'' \right) - 3 P_\Lambda \frac{\varphi'}{b} = 0 } \tag{N_corr}$$

O fator $(1+b'^2)$ é corretamente eliminado pelo termo da Hessiana angular.

---

## 4. Equivalência e Redução no Shell de Noether

Diferenciando a primeira integral circular (2), obtemos a aceleração angular $\varphi''$:

$$\frac{v''}{v} = f' - 3 \frac{b'}{b} - \frac{\rho_\Lambda'}{\rho_\Lambda}$$

Substituindo $\varphi''$ na equação normal $(N_{\text{corr}})$ e multiplicando por $\frac{b}{\varphi'}$ no ramo regular ($\rho_\Lambda \varphi' \neq 0$):

$$b \rho_\Lambda b'' - b b' \rho_\Lambda \left( f' - 3 \frac{b'}{b} - \frac{\rho_\Lambda'}{\rho_\Lambda} \right) - 3 P_\Lambda = 0 \implies b \rho_\Lambda b'' + b b' (\rho_\Lambda' - f' \rho_\Lambda) + 3 b'^2 \rho_\Lambda - 3 P_\Lambda = 0$$

Pela identidade de Noether (N') demonstrada em `2_29.md` ($\rho_\Lambda' - f' \rho_\Lambda = -3 \frac{b'}{b} (\rho_\Lambda + P_\Lambda)$), a equação acima se reduz a:

$$b \rho_\Lambda b'' + b b' \left( -3 \frac{b'}{b} (\rho_\Lambda + P_\Lambda) \right) + 3 b'^2 \rho_\Lambda - 3 P_\Lambda = 0 \implies \rho_\Lambda b'' - 3 P_\Lambda \frac{1+b'^2}{b} = 0$$

Esta é exatamente a **equação radial clássica**.

### Conclusão Física Fundamental:
A projeção normal da imersão **não introduz uma dinâmica independente** das equações métrica, dilatônica e da primeira integral circular. O sistema dinâmico é inteiramente governado por duas equações independentes de segunda ordem para $(b, f)$, fechando os graus de liberdade de forma consistente e auto-suficiente.
