# Modelo GDQ v2.29 — Auditoria Algébrica de Noether e Sistema DAE Final

Este documento realiza a auditoria algébrica completa exigida em `2_28.md` para o regime cosmológico plano. Provamos que a identidade de Noether simplifica drasticamente a equação radial da imersão, eliminando os termos de terceira ordem e revelando um sistema diferencial-algébrico (DAE) de segunda ordem fechado e consistente.

## 1. Passo 1 — Verificação da Identidade de Noether

O tensor métrico-dilatônico é definido por:

$$E_{\mu\nu} = G_{\mu\nu} + \nabla_\mu \nabla_\nu f + h_{\mu\nu} \left( \frac{1}{2} |\nabla f|^2 - \Box f \right)$$

A invariância de difeomorfismo da ação clássica garante a seguinte identidade de Noether geral (válida fora do shell métrico):

$$\nabla^\mu \left( e^{-f} E_{\mu\nu} \right) = \frac{1}{2} e^{-f} \mathcal{D}_f \partial_\nu f$$

onde $\mathcal{D}_f = R[h] + 2\Box f - |\nabla f|^2$ é o operador da equação dilatônica. Expandindo a derivada covariante do lado esquerdo:

$$\nabla^\mu \left( e^{-f} E_{\mu\nu} \right) = e^{-f} \left( \nabla^\mu E_{\mu\nu} - \partial^\mu f E_{\mu\nu} \right)$$

Como a equação métrica impõe $\Lambda^{\mu\nu} = -A E^{\mu\nu}$, a identidade dita:

$$\boxed{ \nabla_\mu \Lambda^{\mu\nu} = \partial_\mu f \Lambda^{\mu\nu} - \frac{A}{2} \mathcal{D}_f \partial^\nu f } \tag{N}$$

### 1.1 Prova Explícita no Ansatz Homogêneo

Projetando a identidade (N) na direção temporal $\nu = \tau$ e usando a parametrização do ansatz onde $\Lambda^{\tau\tau} = \rho_\Lambda$ e $\Lambda^{ij} = P_\Lambda h^{ij}$:

- Lado esquerdo (divergência temporal):
  $$\nabla_\mu \Lambda^{\mu\tau} = \rho_\Lambda' + 3H (\rho_\Lambda + P_\Lambda)$$
- Lado direito (termo dilatônico):
  $$\partial_\mu f \Lambda^{\mu\tau} = f' \rho_\Lambda$$

Substituindo a expressão explícita para $\mathcal{D}_f$ no ansatz:

$$\rho_\Lambda' + 3H (\rho_\Lambda + P_\Lambda) - f' \rho_\Lambda = \frac{A}{2} f' \left[ 6\left(\frac{b''}{b} + H^2 + \frac{1}{b^2}\right) - 2f'' - 6Hf' + (f')^2 \right]$$

No shell do dilaton ($\mathcal{D}_f = 0$), a identidade simplifica-se exatamente para:

$$\boxed{ \rho_\Lambda' + 3H (\rho_\Lambda + P_\Lambda) = f' \rho_\Lambda } \tag{N'}$$

Esta relação elimina a necessidade de calcular $b'''$ e $f'''$, provando que a divergência de $\Lambda$ é inteiramente determinada pelo dilaton no shell físico.

## 2. Passo 2 — Simplificação da Equação Radial

A equação radial obtida em `2_27.md` é:

$$\rho_\Lambda b'' - 3 P_\Lambda \frac{1+b'^2}{b} - \rho_\Lambda f' b' + \left[ \rho_\Lambda' + 3H(\rho_\Lambda + P_\Lambda) \right] b' = 0$$

Substituindo a identidade de Noether (N') no último termo:

$$\rho_\Lambda b'' - 3 P_\Lambda \frac{1+b'^2}{b} - \rho_\Lambda f' b' + \left[ f' \rho_\Lambda \right] b' = 0$$

Os termos com $f' b'$ **cancelam-se identicamente**:

$$- \rho_\Lambda f' b' + \rho_\Lambda f' b' = 0$$

A equação radial da imersão reduz-se exatamente a:

$$\boxed{ \rho_\Lambda b'' - 3 P_\Lambda \frac{1+b'^2}{b} = 0 } \tag{I}$$

Esta é uma equação puramente de **segunda ordem** para $b(\tau)$ e $f(\tau)$, pois $\rho_\Lambda$ contém derivadas de primeira ordem ($b', f'$) e $P_\Lambda$ contém derivadas de segunda ordem ($b'', f''$).

## 3. Passo 3 — Coordenada Circular $\varphi$ e o Vínculo de Lapse

A primeira integral da equação de movimento para a coordenada $\Theta = \varphi(\tau)$ fornece:

$$\varphi' = \frac{J_0 e^f}{R_0^2 b^3 \rho_\Lambda}$$

Substituindo esta relação no vínculo do lapse em tempo próprio:

$$\lambda_\tau^2 = 1 + b'^2 + R_0^2 \varphi'^2 \implies \boxed{ \lambda_\tau^2 = 1 + b'^2 + \frac{J_0^2 e^{2f}}{R_0^2 b^6 \rho_\Lambda^2} } \tag{L}$$

## 4. Passo 4 — Contagem de Graus de Liberdade e DAE (Auditoria Final)

O sistema cosmológico plano final para o par dinâmico $(b(\tau), f(\tau))$ consiste em:

1. **Equação Dilatônica (EDO de 2ª ordem):**
   $$6\left(\frac{b''}{b} + \frac{b'^2 + 1}{b^2}\right) - 2f'' - 6\frac{b'}{b}f' + (f')^2 = 0 \tag{1}$$
2. **Equação Radial da Imersão (EDO de 2ª ordem):**
   $$\rho_\Lambda b'' - 3 P_\Lambda \frac{1+b'^2}{b} = 0 \tag{2}$$
3. **Vínculo do Lapse (Restrição Algébrica):**
   $$\Psi(b, b', f, \rho_\Lambda) \equiv 1 + b'^2 + \frac{J_0^2 e^{2f}}{R_0^2 b^6 \rho_\Lambda^2} - \lambda_\tau^2 = 0 \tag{3}$$

onde $\rho_\Lambda(b, b', f')$ e $P_\Lambda(b, b', b'', f', f'')$ são funções explícitas dos estados.

### Análise de Consistência e Graus de Liberdade:

- **Se $\lambda_\tau(\tau)$ for um background fixado externamente:**
  Temos 2 variáveis dinâmicas ($b, f$) sujeitas a duas EDOs de segunda ordem (1, 2) e um vínculo de primeira ordem (3). O sistema é **sobredeterminado** (3 equações para 2 variáveis), o que significa que soluções só existem para escolhas muito específicas do background $\lambda_\tau(\tau)$.
  
- **Se $\lambda_\tau(\tau)$ for livre (determinado pela solução):**
  O sistema (1, 2) determina unicamente a trajetória cosmológica $(b(\tau), f(\tau))$ a partir de 4 dados iniciais livres:
  $$b(0), \quad b'(0), \quad f(0), \quad f'(0)$$
  O background $\lambda_\tau(\tau)$ é então calculado a posteriori via equação (3) para que a consistência lorentziana seja preservada. Neste caso, o sistema é **perfeitamente determinado e localmente bem-posto** desde que $\rho_\Lambda \neq 0$ e $b > 0$.
