# Q73 — Aharonov--Bohm via GDQ

## Enunciado

1. potenciais de calibre como propriedades físicas do vácuo geométrico;
2. $\mathbf A$ como cisalhamento/arrasto local da malha Hermitiana;
3. $\mathbf B$ como vorticidade/torção concentrada no solenoide;
4. fase AB como holonomia/topologia do domínio perfurado;
5. ausência de ação fantasmagórica à distância;
6. possíveis correções para solenoides reais por impedância de interface.

Esta questão continua a Q46. A Q46 fechou o setor ideal de holonomia. A Q73
deve explicitar a ontologia local e o caminho para aparelhos reais.
