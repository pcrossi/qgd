# Q6 — Parâmetro de fluxo

Documento canônico: [questao_06.md](questao_06.md)

Status vigente: fechada como definição/convenção dimensional.

Resumo:

- $\tau$ é parâmetro real de fluxo geométrico/difusivo;
- $\tau$ não é tempo físico cronológico;
- tempo físico é $t$;
- variável causal complexa: $z_\tau=\tau+i\nu_0 t$;
- $d\tau/\tau$ implementa escala logarítmica sem tornar $\tau$ adimensional.
