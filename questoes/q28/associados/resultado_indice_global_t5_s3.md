# Q28 — Índice global em $T^5\times S^3$

Para $c_2=a_4+b_1u_3$:

$$
\operatorname{Ind}D^+=\frac16\langle a_4b_1,[T^5]\rangle.
$$

| $N_{ab}$ | índice |
|---:|---:|
| 0 | 0 |
| 6 | 1 |
| 12 | 2 |
| 18 | 3 |
| 24 | 4 |
| 30 | 5 |

O índice três requer $N_{ab}=18$.

Para uma linha puxada apenas de $T^5$, $c_1^4=0$ por dimensão e o
índice global é zero.
