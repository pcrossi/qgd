# Q75 — Efeito Sagnac via GDQ

## Enunciado

Resolver o efeito Sagnac no arcabouço GDQ.

Objetivo:

1. recuperar o deslocamento temporal e de fase padrão;
2. interpretar o efeito como holonomia da conexão de simultaneidade/relógio;
3. separar Sagnac de Aharonov--Bohm eletromagnético;
4. tratar a rotação como contorno/aparelho, não como rotação global do
   background;
5. indicar como refinamentos materiais entram por $\mathsf R_{\rm rot}$.
