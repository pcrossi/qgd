# Q29 — Bloco 1 — Modo de ordem eletrofraco

## 1. Objetivo

A Q29 pergunta se existe Higgs ou substituto. Na GDQ, a resposta correta é:

\[
\boxed{
\text{existe um modo de ordem eletrofraco efetivo.}
}
\]

Esse modo deve reproduzir o Higgs no limite de baixa energia, mas não precisa
ser ontologicamente fundamental.

---

## 2. Dependência da Q28

Usamos a Q28 como teorema condicional:

\[
E_{\rm int}=E_C\oplus E_W\oplus L_Y,
\]

com:

\[
SU(2)_L\times U(1)_Y
\]

já estruturado como setor efetivo.

Assim, podemos definir o modo eletrofraco como seção:

\[
\boxed{
\Phi_{\rm EW}\in\Gamma(E_W\otimes L_Y^{1/2}).
}
\]

Portanto:

\[
\boxed{
\Phi_{\rm EW}\sim(1,2)_{1/2}.
}
\]

---

## 3. Interpretação GDQ

Na GDQ, \(\Phi_{\rm EW}\) é um modo coletivo geométrico do par:

\[
(g_{\mu\bar\nu},f,\bar f)
\]

com possível componente torsional:

\[
B_{\mu\nu\lambda}.
\]

Esquematicamente:

\[
\boxed{
\Phi_{\rm EW}
=
\Pi_{(1,2)_{1/2}}
\left(
\delta g,\delta f,\delta\bar f,\delta B
\right).
}
\]

Aqui:

\[
\Pi_{(1,2)_{1/2}}
\]

é o projetor espectral sobre o modo com números quânticos eletrofracos.

---

## 4. Condição de existência

O modo deve ser autovetor da Hessiana efetiva:

\[
\boxed{
\mathcal O_{\rm GDQ}^{(2)}
\Phi_{\rm EW}
=
\lambda_{\rm EW}
\Phi_{\rm EW}.
}
\]

Para haver quebra espontânea:

\[
\boxed{
\lambda_{\rm EW}<0
}
\]

no ponto simétrico.

Isso equivale ao termo:

\[
-\mu_{\rm EW}^2\Phi^\dagger\Phi.
\]

---

## 5. O que substitui o Higgs fundamental

No limite efetivo, \(\Phi_{\rm EW}\) obedece à mesma álgebra de um dupleto de
Higgs. Ontologicamente, porém:

\[
\boxed{
\Phi_{\rm EW}
\text{ é modo normal geométrico, não campo fundamental independente.}
}
\]

Isso preserva a estrutura da GDQ: o Modelo Padrão aparece como descrição
efetiva, não como ponto de partida.

---

## 6. Status

\[
\boxed{
\text{modo de ordem eletrofraco definido condicionalmente à Q28.}
}
\]

Atualização posterior: o documento final consolidou o representante de Hopf
\(\Phi_{\rm EW}=\rho u/\sqrt2\), com \(u\sim(1,2)_{1/2}\), como modo de ordem
no setor reduzido. A pendência remanescente é a elevação/globalização das
normas e transportes, não a existência do modo efetivo.
