# Q25 sign problem algorithm

GDQ has not yet solved the sign problem as a reproducible computational
algorithm.

Required closure:

1. estimator for phase-sensitive observables;
2. polynomial variance bound in a specified class;
3. mixing and autocorrelation control;
4. nodal/holonomy treatment;
5. benchmark suite;
6. complexity proof.

Domain decomposition with transmission/reflection matrices is the proposed
route to make the geometric surgery idea simulable.
